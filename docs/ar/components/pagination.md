# Pagination ترقيم الصفحات

تنقّل بين الصفحات: الصفحة السابقة / أرقام الصفحات / علامة الحذف / الصفحة التالية / الإجمالي /
مبدّل حجم الصفحة / الانتقال إلى صفحة. خوارزمية انكماش نافذة الصفحات (بقاء الصفحة الأولى والأخيرة
ظاهرتين دائمًا، وعرض الصفحات المجاورة حول الصفحة الحالية، وإخراج علامة الحذف فقط عند وجود فجوة
حقيقية) مُنفّذة كدالة نقية في نواة `@lh-ui/share`.

## الاستخدام الأساسي

`total` هو العدد الإجمالي للعناصر (إلزامي)، والحجم الافتراضي 10 عناصر لكل صفحة.

```vue
<template>
  <lh-pagination :total="120" />
</template>
```

## الإجمالي ومبدّل حجم الصفحة

`show-total` يعرض الإجمالي؛ و`show-size-changer` يعرض مبدّل عدد العناصر في الصفحة (يتكفّل به
مكوّن picker المدمج في uni).

```vue
<template>
  <lh-pagination :total="480" show-total show-size-changer />
</template>
```

## الانتقال إلى صفحة

`show-jumper` يعرض حقل الانتقال؛ بعد إدخال رقم الصفحة يتم التأكيد بزر الإدخال (confirm) أو عند
فقدان التركيز، وتُقيَّد القيم الخارجة عن النطاق تلقائيًا.

```vue
<template>
  <lh-pagination :total="480" show-total show-jumper />
</template>
```

## الوضع المبسّط

`simple` يطوي منطقة أرقام الصفحات ويعرض «الصفحة الحالية / إجمالي الصفحات» فقط.

```vue
<template>
  <lh-pagination :total="480" simple show-jumper />
</template>
```

## الاستخدام المتحكَّم به

تُدار الصفحة الحالية عبر `v-model:current`.

```vue
<template>
  <lh-pagination v-model:current="page" :total="95" />
  <text>الصفحة الحالية: {{ page }}</text>
</template>

<script setup>
import { ref } from 'vue'
const page = ref(2)
</script>
```

## حجم الصفحة والتعطيل

`v-model:page-size` يتحكم في حجم الصفحة و`page-sizes` يخصّص الخيارات؛ وإذا خرجت الصفحة الحالية عن
النطاق بعد تغيير الحجم فستُقيَّد تلقائيًا؛ و`disabled` يعطّل ترقيم الصفحات بالكامل.

```vue
<template>
  <lh-pagination
    v-model:page-size="pageSize"
    :total="480"
    show-size-changer
    :page-sizes="[10, 20, 50, 100]"
  />
  <text>عدد العناصر في الصفحة: {{ pageSize }}</text>
  <lh-pagination :total="480" disabled />
</template>

<script setup>
import { ref } from 'vue'
const pageSize = ref(20)
</script>
```

## Props

| الخاصية | الوصف | النوع | الافتراضي |
| --- | --- | --- | --- |
| total | العدد الإجمالي للعناصر (إلزامي) | `number` | — |
| pageSize | عدد العناصر في الصفحة (يُتحكَّم فيه عبر حدث `update:pageSize`) | `number` | `10` |
| current | الصفحة الحالية (`v-model:current`) | `number` | — |
| pageSizes | خيارات عدد العناصر في الصفحة | `number[]` | `[10, 20, 30, 40]` |
| showTotal | إظهار الإجمالي | `boolean` | `false` |
| showSizeChanger | إظهار مبدّل حجم الصفحة | `boolean` | `false` |
| showJumper | إظهار حقل الانتقال إلى صفحة | `boolean` | `false` |
| simple | الوضع المبسّط | `boolean` | `false` |
| disabled | هل هو معطّل | `boolean` | `false` |
| sx | خصائص التخطيط السريع | `LhSxProps` | — |

## Events

| اسم الحدث | الوصف | معاملات الدالة |
| --- | --- | --- |
| update:current | يُطلق عند تغيّر الصفحة الحالية، مع `v-model:current` | `(page: number)` |
| update:pageSize | يُطلق عند تغيّر حجم الصفحة، مع `v-model:page-size` | `(size: number)` |
| change | يُطلق عند تغيّر الصفحة الحالية (أرقام الصفحات والتنقل السابق / التالي والانتقال كلها تطلقه) | `(page: number)` |
| size-change | يُطلق عند تغيّر حجم الصفحة | `(size: number)` |

## إمكانية الوصول

- العقدة الجذر تحمل `role="navigation"` + `aria-label="pagination"`
- زر الصفحة الحالية يحصل تلقائيًا على `aria-current="page"`، ولكل زر من أزرار الصفحات وأزرار
  السابق / التالي `aria-label` خاص به (من مفاتيح حزمة اللغة `pagination.page` / `prev` / `next`)،
  والرمزين المجردَين «‹» «›» يُخفيان عبر `aria-hidden`
- أزرار الصفحات وأزرار التنقل تحمل `role="button"` وتُخرج `aria-disabled` عند التعطيل
- علامة الحذف عنصر عرضي بحت يحمل `aria-hidden` ولا يعترض قراءة الشاشة

## اختلافات المنصات

- **تفاعل لمسي مرسوم بـ view ومتاح على كل المنصات**: عناصر `<nav>` / `<button>` / `<ul>` /
  `<span>` في نسخة Vue 3 تُستبدل بـ `<view>` / `<text>` في هذه المكتبة (لأن WXSS يحظر محدّدات
  الوسوم فتُطبَّق الأنماط بالأصناف)؛ وأرقام الصفحات والتنقل تُفعَّل عبر `@click` وتتصرف بالطريقة
  نفسها على H5 وبرنامج WeChat المصغّر دون أي اعتماد على واجهات منصة بعينها.
- **منطق علامة الحذف عند فائض الصفحات يسكن في core**: خوارزمية انكماش النافذة (بقاء الصفحة الأولى
  والأخيرة، وعرض صفحة واحدة مجاورة على كل جانب من الصفحة الحالية، والالتصاق بالحواف عند نقص
  الصفحات، وإخراج علامة الحذف فقط عند وجود فجوة حقيقية) هي الدالة النقية `getPaginationRange`
  في نواة `@lh-ui/share`؛ والقيد `clampPage` وحساب عدد الصفحات `getPageCount` قادمان من core
  أيضًا — ولا يضيف هذا المستودع سوى طبقة التفاعلية اللاصقة.
- **مبدّل الحجم يتكفّل به picker المدمج**: لا يوجد `<select>` في uni، لذا يُحمل `show-size-changer`
  عبر `<picker mode="selector">` المدمج في uni بخياراته من `page-sizes`؛ وتأتي قيمة حدث change
  في `event.detail.value` (فهرس الخيار). على H5 تُفتح لوحة منتقي uni، وفي البرنامج المصغّر
  يُفتح منتقي العجلة الأصلي.
- **تأكيد حقل الانتقال يحدث في وقت مختلف**: لا يملك input في uni حدث change أصليًا، لذا يتم
  التأكيد عند الإدخال (confirm — يطلقه زر الإدخال على H5 وزر «تم» في لوحة مفاتيح البرنامج المصغّر
  على حد سواء) أو عند فقدان التركيز (blur)، وتُقرأ قيمة حدث الإدخال من `event.detail.value`
  (السابقة نفسها التي سلكها lh-input-number)؛ ولا تُمرَّر السمتان الأصليتان `min` / `max` — بل
  يُقيَّد رقم الصفحة دائمًا بـ `clampPage` من core. نسخة Vue 3 تعود إلى الصفحة الأولى إذا أُفرغ
  الحقل ثم فُقد التركيز؛ وهذه المكتبة تُحصّن ذلك بمنع الانتقال (السلاسل الفارغة والأرقام غير
  الصالحة لا تطلق أي حدث).
- **مظهر التعطيل عبر صنف احتياطي**: أنماط التعطيل في مصدر أنماط share مكتوبة على الصنف الزائف
  `&:disabled` (ويطابق عناصر button فقط)، وview لا يملك هذا الصنف الزائف؛ لذا يضيف المكوّن
  قاعدة داخلية `lh-pagination__btn--disabled` بالرمز نفسه (`--lh-disabled-text-color`) وفق
  سابقة الاحتياط الداخلية في lh-segmented / lh-input-number (ولا يدخل المنتج المنقّى).
- **سمات الوصول تُربط واحدًا واحدًا**: عقد `aria-current` / `aria-label` لأزرار الصفحات تحدده
  `getPaginationItemAria` من share؛ ولأن مترجم القوالب في البرنامج المصغّر لا يدعم `v-bind`
  بكائن، تُبسّط طبقة اللصق حزمة السمات إلى روابط صريحة لكل عنصر.
- **خلاصة النقل**: pagination مكوّن تبديل بحت بلا قياسات ولا طبقات عائمة ولا اعتماد على
  document؛ ونطاق الصفحات والقيد وسمات الوصول تُنتجها جميعًا الدوال النقية لنواة
  `@lh-ui/share`، ولا يكتب المستودع سوى الطبقة التفاعلية اللاصقة. الواجهة البرمجية مطابقة
  تمامًا لنسخة Vue 3 (`total` / `pageSize` / `current` / `pageSizes` / `showTotal` /
  `showSizeChanger` / `showJumper` / `simple` / `disabled` / `sx`).
