# Rate (تقييم)

تقييم بالنجوم: انقر لاختيار النجوم، مع أنصاف نجوم ونص تقييم اختياريين؛ وفي وضع القراءة فقط يُخرج التقييم كنص لقارئات الشاشة. تأتي مستويات الملء والقصّ والخطوات من دوال نقية في نواة `@lh-ui/share`.

## الاستخدام الأساسي

```vue
<template>
  <lh-rate v-model="value" />
</template>

<script lang="ts" setup>
import { ref } from 'vue'
const value = ref(3)
</script>
```

## نصف نجمة

`allow-half` يفعّل نصف النجمة: على H5 يُسجَّل النقر على النصف الأيسر من النجمة 0.5 (استنادًا إلى الإزاحة الأفقية للنقر).

```vue
<template>
  <lh-rate v-model="value" allow-half />
</template>
```

## القراءة فقط ونص التقييم

`readonly` يدخل فرع العرض الصرف（`role="img"` ونص التقييم عبر `aria-label`）；و`show-score` يضيف نص التقييم، بينما يخصّص `score-template` القالب（بالعنصر النائب `{n}`）.

```vue
<template>
  <lh-rate :model-value="3.5" readonly allow-half show-score />
  <lh-rate :model-value="4" readonly show-score score-template="{n} نقطة" />
</template>
```

## عدد النجوم والرمز المخصص

`max` يضبط الحد الأعلى لعدد النجوم（مع القصّ إلى [0, max]）；و`character` يستبدل الرمز الافتراضي `★`.

```vue
<template>
  <lh-rate :model-value="5" :max="8" character="墨" />
</template>
```

## التعطيل

`disabled` يعطّل المجموعة بأكملها: لا يكون للنقر أي أثر، وتُضاف `lh-rate--disabled` و`aria-disabled` إلى العقدة الجذرية.

## الخصائص

| الخاصية | الوصف | النوع | الافتراضي |
| --- | --- | --- | --- |
| modelValue / v-model | التقييم الحالي | `number` | `0` |
| max | الحد الأعلى لعدد النجوم | `number` | `5` |
| allow-half | السماح بأنصاف النجوم | `boolean` | `false` |
| readonly | قراءة فقط（عرض صرف） | `boolean` | `false` |
| disabled | تعطيل | `boolean` | `false` |
| character | رمز مخصص | `string` | — |
| show-score | إظهار نص التقييم | `boolean` | `false` |
| score-template | قالب التقييم（العنصر النائب `{n}`） | `string` | — |
| customClass | صنف مخصص（يُمرَّر إلى العقدة الجذرية） | `string` | — |
| sx | خصائص التخطيط المختصرة sx | `LhSxProps` | — |

## الأحداث

| الحدث | الوصف | المعاملات |
| --- | --- | --- |
| update:modelValue / change | تغيّر التقييم（لا تُكرَّر القيمة نفسها） | `(value: number)` |

## الفروقات بين المنصات

- **كشف نصف النجمة على H5 فقط**：يعتمد على الإزاحة الأفقية لحدث النقر（`offsetX`），وهو حقل **لا تحمله أحداث برنامج WeChat المصغّر**، فينخفض النقر هناك إلى نجمة كاملة. إذا احتجت دقة نصف النجمة على البرنامج المصغّر، فنفّذها بنفسك عبر أحداث اللمس + حساب الإزاحة غير المتزامن بـ`uni.createSelectorQuery`（انتبه إلى أن SelectorQuery غير متزامن）.
- **حامل النجمة**：تتحول نجوم `<button>` الخاصة بـ plus إلى `<view role="radio">`（لأن button في MP لا يمكن تصفير أنماطه الافتراضية），ويُعبَّر عن التعطيل بحارس النقر + صنف التعديل `--disabled` + `aria-disabled`.
- **الخطوات بلوحة المفاتيح على H5 فقط**：أسهم الاتجاهات ±1（±0.5 مع أنصاف النجوم），وHome للتصفير وEnd للتعبئة الكاملة؛ وليس لدى البرامج المصغّرة أحداث لوحة مفاتيح فلا فرق سلوكي.
- **نص التقييم**：يأتي من `rate.stars` في حزم لغات share（`{n} 星`، بتسع لغات كاملة），ويمكن لـ`score-template` تجاوزه.

::: tip الفروقات عن إصدار Vue 3
- دلالات المنطق（القصّ، مستويات الملء، الخطوات، aria）تطابق plus تمامًا（نواة share نفسها）.
- أُضيفت خاصية `customClass`：لا تستطيع الأصناف المخصصة في uni-app اختراق `styleIsolation`، فيتم تمريرها عبر الخاصية.
- ينخفض كشف نصف النجمة إلى نجمة كاملة على البرنامج المصغّر（انظر «الفروقات بين المنصات»）.
:::
