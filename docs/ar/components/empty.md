# فارغ Empty

عنصر نائب عند غياب البيانات، ويأتي مع رسم توضيحي بنمط 水墨 (رسم الحبر).

## الاستخدام الأساسي

```vue
<template>
  <lh-empty />
</template>
```

عند عدم تمرير `description` تُؤخَذ القيمة من `empty.description` في حزمة اللغة
(بالدائرة الصينية «暂无数据»)، وتتبدّل تلقائيًا عند تبديل لغة ConfigProvider.

## نص مخصص

```vue
<template>
  <lh-empty description="لم يجف الحبر بعد، لا شيء لعرضه" />
</template>
```

## صورة مخصصة

```vue
<template>
  <lh-empty image="https://placeholder.invalid/empty.png" description="فارغ تمامًا" />
</template>
```

## رسم ذاتي عبر الفتحة

يمكن للفتحة الافتراضية أن تحلّ كاملًا محل الرسم الافتراضي (وعند تمرير `image` لا يُعرَض الرسم الافتراضي
أيضًا).

```vue
<template>
  <lh-empty description="لا توجد مفضلات">
    <view class="my-illustration">🎨</view>
  </lh-empty>
</template>
```

## Props

| الخاصية | الوصف | النوع | الافتراضي |
| --- | --- | --- | --- |
| description | نص وصف الحالة الفارغة (يُؤخَذ من empty.description في حزمة اللغة عند عدم التمرير) | `string` | — |
| image | عنوان صورة مخصص (بديل للرسم الافتراضي) | `string` | — |
| customClass | صنف مخصّص | `string` | — |
| sx | خصائص تخطيط سريعة | `LhSxProps` | — |

## Slots

| الفتحة | الوصف |
| --- | --- |
| default | رسم ذاتي (يحلّ محل الرسم الافتراضي عند تمريره) |

::: tip الرسم الافتراضي على طرف البرنامج المصغر
يحتفظ H5 بالرسم التوضيحي المضمّن `<svg>` (كامل التفاصيل مع تلوين السمة)؛ أما البرنامج المصغر فلا
يدعم svg، فيُستبدل الرسم الافتراضي بنسخة مبسّطة مرسومة بـ CSS، تأخذ ألوانها من متغيّرات السمة،
وتتكيّف تلقائيًا مع الوضع الفاتح والداكن.
:::
