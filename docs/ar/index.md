::: tip العلاقة مع بقية المنصات في العائلة
هذا المسجل هو واجهة uni-app لسلالة الويب في عائلة lh-ui، ويشارك `@lh-ui/vue3` (plus) و`@lh-ui/vue2`
و`@lh-ui/react` الدوالّ النقية للنواة ومصادر الأنماط في `@lh-ui/share`. تسمية Props مطابقة تقريبًا
لنسخة Vue3؛ وللاطلاع على الفروق بين المنصات راجع [اختلافات API عن نسخة Vue3](/ar/guide/differences).
:::
