::: tip Связь с другими платформами семейства
Эта библиотека — версия uni-app в web-направлении семейства lh-ui; она разделяет чистые функции core и источники стилей `@lh-ui/share` с `@lh-ui/vue3` (plus), `@lh-ui/vue2` и `@lh-ui/react`.
Имена Props в основном совпадают с версией для Vue3, платформенные отличия см. в
[Отличиях API от версии Vue3](/ru/guide/differences).
:::
