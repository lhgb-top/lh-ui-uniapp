# Transfer (список переноса)

Список из двух панелей с перемещением через флажки. Разделение данных, фильтрация, выделение
всего и логика перемещения полностью берутся из чистых функций core `@lh-ui/share`
(`partitionTransferData` / `filterTransferItems` / `toggleTransferCheckAll` /
`moveTransferKeys` и др.); слой компонента отвечает только за отрисовку, события и навигацию
с клавиатуры. Обе панели имеют `role="listbox"` (паттерн listbox APG).

## Базовое использование

```vue
<template>
  <lh-transfer v-model="source" :data="items" @change="onChange" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import type { LhTransferItem } from '@lh-ui/share/core/transfer'

const source = ref<Array<string | number>>(['a'])
const items: LhTransferItem[] = [
  { key: 'a', label: 'А' },
  { key: 'b', label: 'Б' },
  { key: 'c', label: 'В', disabled: true },
  { key: 'd', label: 'Г' },
]

function onChange(keys: Array<string | number>, direction: 'left-to-right' | 'right-to-left') {
  console.log(keys, direction)
}
</script>
```

`v-model` хранит список ключей левой (исходной) панели: элементы, чьи ключи присутствуют в
`modelValue`, отображаются в левом столбце, остальные — в правом. Отметьте любой элемент и
нажмите кнопки › / ‹ в центре, чтобы перенести его: после этого срабатывают `update:modelValue`
и `change` (с направлением `'left-to-right'` / `'right-to-left'`), а набор отмеченных
очищается после каждого перемещения.

В верхней части каждой панели есть поле поиска (постоянно активно, как в версии Vue3),
выполняющее фильтрацию по тексту без учёта регистра; заголовок панели показывает счётчик
«количество на стороне / всего», а также флажок «выбрать всё» (промежуточное состояние несёт
`indeterminate`).

`data` — это `LhTransferItem[]`: `key` уникален, `label` — отображаемый текст (при отсутствии
показывается `key`), `disabled` отключает элемент (нельзя отметить, исключается из «выбрать
всё», нельзя перенести).

## Отключение

`disabled` отключает весь компонент: отметка, выделение всего, поиск и перемещение полностью
блокируются.

```vue
<template>
  <lh-transfer v-model="source" :data="items" disabled />
</template>
```

## API

### Props

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| data | Полный набор данных | `LhTransferItem[]` | — |
| modelValue | Список ключей левой (исходной) панели (контролируется через v-model) | `Array<string \| number>` | `[]` |
| disabled | Отключить | `boolean` | `false` |
| sx | свойства быстрой раскладки sx | `LhSxProps` | — |

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Список ключей левой (исходной) панели изменился (для v-model) | `(keys: Array<string \| number>)` |
| change | Срабатывает после завершения перемещения | `(keys: Array<string \| number>, direction: 'left-to-right' \| 'right-to-left')` |

### LhTransferItem

| Поле | Описание | Тип |
| --- | --- | --- |
| key | Уникальный ключ | `string \| number` |
| label | Отображаемый текст (при отсутствии показывается key) | `string` |
| disabled | Отключён (нельзя отметить / исключён из «выбрать всё» / нельзя перенести) | `boolean` |

### Доступность

- Обе панели имеют `role="listbox"` + `aria-multiselectable`; элементы — `role="option"` с
  `aria-selected` / `aria-disabled`
- У каждой панели своё поле поиска с `aria-label`; кнопки переноса также несут `aria-label`
  («Перенести вправо» / «Перенести влево»)
- Флажок «выбрать всё» несёт промежуточное состояние через `indeterminate`; отключённые
  элементы исключаются везде (отметка, выделение всего, перемещение)

::: tip Платформенные отличия (отличия от версии Vue3)
- **Обхват API строго соответствует исходникам Vue3**: здесь предоставлено только то, что
  есть в версии Vue3 — `data` / `modelValue` / `disabled` / `sx`. Возможности, часто
  встречающиеся в других библиотеках, но отсутствующие в исходниках Vue3 — `titles`
  (заголовки панелей), `filterable` (переключатель поиска), `props` (кастомные имена
  полей), `left/right-default-checked` (ключи, отмеченные по умолчанию) — намеренно
  не добавлены; заголовки панелей берутся из ключей локалей share
  `transfer.sourceTitle` / `transfer.targetTitle` (доступны на десяти языках), а
  поле поиска сохраняет постоянно активную форму версии Vue3 (без переключателя).
- **Оба списка несёт scroll-view**: списки `<ul>` / `<li>` версии Vue3 здесь заменены на
  `<scroll-view scroll-y>` + `<view>` (в Mini Program обычный `view` не может надёжно
  прокручиваться при переполнении), поведение одинаково на H5 и в WeChat Mini Program;
  стили списка по-прежнему берутся из `.lh-transfer-panel__list` пакета share.
- **Перенос кнопками доступен на всех платформах**: кнопки › / ‹ в центре — это встроенный
  `<button>` uni, который можно нажимать и на H5, и в Mini Program; платформенных отличий
  здесь нет, а отключённое состояние несёт атрибут `disabled`.
- **Навигация с клавиатуры только на H5**: клавиши паттерна listbox APG — ↑/↓ внутри
  отфильтрованного списка (с пропуском отключённых, без зацикливания), Enter / Space для
  отметки элемента в фокусе, ←/→ для переноса фокуса между панелями, Escape для сброса
  фокуса — работают только на H5; в Mini Program нет событий клавиатуры, весь блок
  вырезается условной компиляцией (мёртвого кода в MP-пакете нет), и roving tabindex
  также формируется только на H5.
- **Флажки отрисовываются вручную**: флажок «выбрать всё» и флажки элементов не используют
  нативный `<input type="checkbox">` (его стиль не контролируется в Mini Program); вместо
  этого применяется `lh-checkbox` из этого пакета (отрисовка через view + lh-icon).
  Состояние по-прежнему записывается компонентом контролируемо, семантика не меняется.
:::
