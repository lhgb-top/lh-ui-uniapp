# Rate (рейтинг)

Рейтинг звёздами: выбор кликом, опциональные полузвёзды и текст оценки; в режиме только для чтения оценка выводится текстом для скринридеров. Уровни заполнения, клампинг и шагирование выполняются чистыми функциями core из `@lh-ui/share`.

## Базовое использование

```vue
<template>
  <lh-rate v-model="value" />
</template>

<script lang="ts" setup>
import { ref } from 'vue'
const value = ref(3)
</script>
```

## Полузвёзды

`allow-half` включает полузвёзды: на H5 клик по левой половине звезды даёт 0,5 (по горизонтальному смещению клика).

```vue
<template>
  <lh-rate v-model="value" allow-half />
</template>
```

## Только чтение и текст оценки

`readonly` переключает в чисто отображаемую ветку (`role="img"`, оценка передаётся в `aria-label`); `show-score` добавляет текст оценки, а `score-template` задаёт его шаблон (плейсхолдер `{n}`).

```vue
<template>
  <lh-rate :model-value="3.5" readonly allow-half show-score />
  <lh-rate :model-value="4" readonly show-score score-template="{n} б." />
</template>
```

## Своё число звёзд и символ

`max` меняет верхний предел звёзд (клампится в [0, max]); `character` заменяет стандартный `★`.

```vue
<template>
  <lh-rate :model-value="5" :max="8" character="墨" />
</template>
```

## Отключение

`disabled` отключает всю группу: клики игнорируются, а на корень добавляются `lh-rate--disabled` и `aria-disabled`.

## Props

| Prop | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue / v-model | Текущая оценка | `number` | `0` |
| max | Предел числа звёзд | `number` | `5` |
| allow-half | Разрешить полузвёзды | `boolean` | `false` |
| readonly | Только чтение (чистое отображение) | `boolean` | `false` |
| disabled | Отключено | `boolean` | `false` |
| character | Свой символ | `string` | — |
| show-score | Показывать текст оценки | `boolean` | `false` |
| score-template | Шаблон оценки (плейсхолдер `{n}`) | `string` | — |
| customClass | Пользовательский класс (пробрасывается на корневой узел) | `string` | — |
| sx | Краткие свойства раскладки sx | `LhSxProps` | — |

## Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue / change | Оценка изменена (то же значение повторно не отправляется) | `(value: number)` |

## Различия между платформами

- **Определение полузвезды работает только на H5**: оно опирается на горизонтальное смещение события клика (`offsetX`), которого **нет в событиях мини-программы** — там клики деградируют до целых звёзд. Если нужна точность полузвезды в мини-программе, реализуйте её самостоятельно через события touch + асинхронный расчёт смещения с `uni.createSelectorQuery` (учтите, SelectorQuery асинхронен).
- **Носитель звезды**: звёзды `<button>` из plus становятся `<view role="radio">` (button в MP не может сбросить стили по умолчанию); отключение выражается охранным условием клика + классом-модификатором `--disabled` + `aria-disabled`.
- **Шагирование с клавиатуры — только H5**: стрелки ±1 (±0,5 с полузвёздами), Home обнуляет, End ставит максимум; в мини-программах нет клавиатурных событий, расхождений в поведении нет.
- **Текст оценки**: берётся из `rate.stars` локалей share (`{n} 星`, все девять языков); `score-template` может его переопределить.

::: tip Отличия от версии для Vue 3
- Логическая семантика (клампинг, уровни заполнения, шагирование, aria) полностью совпадает с plus (общий core share).
- Добавлен prop `customClass`: в uni-app пользовательские классы не проникают сквозь `styleIsolation`, поэтому пробрасываются через prop.
- Определение полузвезды деградирует до целых звёзд в мини-программе (см. «Различия между платформами»).
:::
