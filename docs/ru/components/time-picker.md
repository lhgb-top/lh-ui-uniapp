# TimePicker (выбор времени)

Компонент для выбора часов, минут и секунд. При нажатии на триггер открывается панель: каждый столбец (часы / минуты / секунды) — это список с независимой вертикальной прокруткой; нажатие на элемент столбца устанавливает выбор, а кнопки «Сейчас / ОК» в нижней части панели подтверждают его.

## Базовое использование

```vue
<template>
  <lh-time-picker v-model="value" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date | null>(new Date(2026, 10, 3, 9, 30, 0))
</script>
```

Значение `format` по умолчанию — `HH:mm:ss`, панель отображает три столбца (часы / минуты / секунды). Нажатие на элемент столбца немедленно устанавливает выбор (панель не закрывается); «ОК» подтверждает значение `Date` и закрывает панель; «Сейчас» заполняет столбцы текущим временем.

## Формат «часы и минуты»

Если `format` не содержит `ss`, панель отображает только столбцы часов и минут, а плейсхолдер также генерируется из `format`:

```vue
<template>
  <lh-time-picker v-model="value" format="HH:mm" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date | null>(new Date(2026, 10, 3, 9, 30, 0))
</script>
```

## Диапазон времени

`start` / `end` ограничивают выбираемый диапазон столбца часов (пересечение с 0~23). Сохранённое значение, выходящее за диапазон, возвращается в интервал, и «Сейчас» также приводится к нему:

```vue
<template>
  <lh-time-picker v-model="value" :start="8" :end="20" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date | null>(new Date(2026, 10, 3, 9, 30, 0))
</script>
```

## Шаг

`step-hour` / `step-minute` / `step-second` задают шаг вариантов в каждом столбце:

```vue
<template>
  <lh-time-picker v-model="value" :step-hour="2" :step-minute="5" :step-second="10" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date | null>(new Date(2026, 10, 3, 9, 30, 0))
</script>
```

## Отключение

`disabled` отключает весь селектор (панель не открывается, а иконка очистки не отображается):

```vue
<template>
  <lh-time-picker v-model="value" disabled />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date | null>(new Date(2026, 10, 3, 9, 30, 0))
</script>
```

## Плейсхолдер и очистка

`placeholder` переопределяет текст плейсхолдера (по умолчанию он генерируется из `format` с использованием ключей локали `timepicker.hour/minute/second`). При наличии значения справа в триггере появляется иконка очистки; нажатие на неё очищает значение (`clearable` по умолчанию `true`):

```vue
<template>
  <lh-time-picker v-model="value" placeholder="Выбрать время напоминания" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date | null>(null)
</script>
```

## API TimePicker

### Props

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| modelValue | Привязанное время | `Date \| null` | `null` |
| size | Размер | `LhTimePickerSize` | `'medium'` |
| disabled | Отключить весь компонент | `boolean` | `false` |
| clearable | Показывать кнопку очистки | `boolean` | `true` |
| placeholder | Плейсхолдер (по умолчанию генерируется из format ключами локали `timepicker.hour/minute/second`) | `string` | — |
| format | Формат времени (столбец секунд появляется только при наличии `ss`) | `string` | `'HH:mm:ss'` |
| readonly | Флаг «только чтение» (триггер — самописная view без состояния ввода, поэтому всегда только для чтения) | `boolean` | `false` |
| arrowControl | Показывать кнопки-стрелки (рендерится только в H5, совместно с шагом с клавиатуры) | `boolean` | `false` |
| start | Начальный час (пересечение с 0~23) | `number` | `0` |
| end | Конечный час (пересечение с 0~23) | `number` | `24` |
| stepHour | Шаг столбца часов | `number` | `1` |
| stepMinute | Шаг столбца минут | `number` | `1` |
| stepSecond | Шаг столбца секунд | `number` | `1` |
| customClass | Пользовательский класс (передаётся в корневой узел) | `string` | — |
| themeVars | Переменные темы на уровне компонента | `Record<string, string>` | — |
| sx | Свойства быстрой раскладки (применяются к корню триггера; плавающая панель не затрагивается) | `LhSxProps` | — |

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Срабатывает при изменении привязанного значения | `(value: Date \| null)` |
| change | Срабатывает при нажатии «ОК» или иконки очистки | `(value: Date \| null)` |

### Доступность

- Триггер несёт `aria-haspopup="dialog"` / `aria-expanded` / `aria-controls` (пакет атрибутов создаётся `getTimePickerTriggerAria` из share и привязывается поэлементно)
- Панель имеет `role="dialog"`, каждый столбец — `role="listbox"` (`aria-label` берётся из ключей локали `timepicker.hourLabel/minuteLabel/secondLabel`), а каждый элемент — `role="option"` с `aria-selected` / `aria-disabled`
- Движок позиционирования — самописная чистая функция (flip / shift от переполнения), без сторонних зависимостей времени выполнения

::: tip Отличия платформ (отличия от версии Vue3)
- **Барабан заменён панелью столбцов scroll-view**: plus использует контейнеры `div` с `overflow-y: auto`, перехватывает колесо мыши через `@wheel.prevent` для шагового перемещения и прокручивает выбранный элемент в зону видимости через `scrollIntoView`; в uni-app каждый столбец — независимый вертикальный `scroll-view` (`scroll-y`) (у `view` в MP нет надёжного overflow-прокрутки), а выбранный элемент подставляется в зону видимости через `scroll-into-view` (в MP нет API `scrollIntoView`). Взаимодействие выбора не изменилось: нажатие на элемент столбца устанавливает выбор, подтверждение — кнопками «Сейчас / ОК».
- **Шаг колесом мыши не перенесён**: прокрутка внутри столбца отдана нативной прокрутке `scroll-view` (в H5 колесо мыши естественно прокручивает длинный список); событие wheel больше не перехватывается для прыжка по шагу. Генерация вариантов с шагом (`step-hour` и др.) соответствует plus.
- **Навигация с клавиатуры только в H5**: триггер открывает панель через Enter/Space/стрелку вниз и переносит фокус в первый столбец; внутри панели ↑↓ перемещаются по настроенному шагу (часы после оборота возвращаются в диапазон start/end), ←→ переносят фокус между столбцами, Enter/Space подтверждают и закрывают, а Escape закрывает через прослушиватель уровня документа (при наложении нескольких слоёв закрывается только верхний). Весь блок обработки вырезается условной компиляцией, мёртвого кода в бандле MP нет.
- **arrowControl только в H5**: кнопки-стрелки зависят от семантики шага с клавиатуры и не отображаются в MP (`v-if` шаблона защищён константой компиляции `LH_IS_H5`).
- **Закрытие по клику вне**: plus слушает клики document; uni-app использует прозрачную маску внутри страницы (клик по маске закрывает без emit change).
- **Самописный триггер**: триггер plus — редактируемый `<input>`; в uni-app триггер рисуется через `<view>` + `<text>` (в MP нет семантики фокуса input внутри триггера, цвет плейсхолдера берётся из модифицирующего класса, а `readonly` фактически всегда включён).
- **Иконка триггера**: plus использует иконку `date`; данная библиотека использует более уместную иконку `clock`.
- **Без переходов появления/исчезания**: `Transition` ненадёжен в MP — панель просто показывается и скрывается, как и у tooltip / dropdown / popover / cascader.
:::
