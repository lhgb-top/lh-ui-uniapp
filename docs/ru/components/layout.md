# Layout (контейнер разметки)

Каркас уровня страницы: `lh-layout` в сочетании с подкомпонентами `lh-header` / `lh-aside` / `lh-main` / `lh-footer` (при использовании easycom теги можно писать напрямую; при импорте по необходимости имена компонентов — `LhLayout` / `LhHeader` / `LhAside` / `LhMain` / `LhFooter`).

## Базовое использование (шапка / контент / подвал)

Контейнеру требуется явная высота: `lh-layout` сам является flex-контейнером с `flex: 1`, поэтому внутри обычного родителя в потоке ему нужно задать высоту через `sx` или внешний стиль, чтобы дочерние header / main / footer распределялись пропорционально.

```vue
<template>
  <lh-layout direction="vertical" :sx="{ h: '240px' }">
    <lh-header>Шапка</lh-header>
    <lh-main>Контент</lh-main>
    <lh-footer>Подвал</lh-footer>
  </lh-layout>
</template>
```

## Направление расположения

`direction` явно задает направление дочерних элементов: по умолчанию `horizontal` (в ряд); автоматически переключается на `vertical` при наличии `lh-aside`, а также может быть задан вручную.

```vue
<template>
  <lh-layout direction="horizontal" :sx="{ h: '80px' }">
    <lh-main>В ряд</lh-main>
    <lh-main>В ряд</lh-main>
  </lh-layout>
  <lh-layout direction="vertical" :sx="{ h: '140px', mt: '12px' }">
    <lh-main>Вертикально</lh-main>
    <lh-main>Вертикально</lh-main>
  </lh-layout>
</template>
```

## Разметка с боковой панелью

При наличии `lh-aside` родитель автоматически переключается на вертикальное направление (header сверху, aside и main в ряд).

```vue
<template>
  <lh-layout direction="vertical" :sx="{ h: '240px' }">
    <lh-header>Шапка</lh-header>
    <lh-layout :sx="{ flex: '1', minHeight: '0px' }">
      <lh-aside :width="140" aria-label="Боковая навигация">Боковая панель</lh-aside>
      <lh-main>Контент</lh-main>
    </lh-layout>
    <lh-footer>Подвал</lh-footer>
  </lh-layout>
</template>
```

`width` принимает `number` (интерпретируется как px) или `string` с единицами (например `'30%'`); если не задан, используется `--lh-layout-aside-width` (по умолчанию 220px).

## Layout Props

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| direction | Направление расположения (автоматически vertical при наличии Aside) | `'horizontal' \| 'vertical'` | `'horizontal'` |
| customClass | Пользовательское имя класса (передается корневому узлу) | `string` | — |
| sx | Удобные свойства разметки sx | `LhSxProps` | — |

## Различия платформ

- **Компонент чистой CSS-разметки**: в share core нет модуля layout, логический слой несет только контекст provide/inject (родитель переключается на вертикальное направление, как только Aside регистрируется), без измерений, без оверлеев и без зависимостей от document; поведение идентично на H5 и в WeChat Mini Program.
- **Замена тегов**: теги `<section>` / `<header>` / `<aside>` / `<main>` / `<footer>` версии plus заменяются на элементы `view` (WXSS запрещает селекторы тегов, стили применяются через классы `lh-layout*`).
- **Семантика landmarks**: роли landmarks, изначально предоставляемые семантическими тегами, восстанавливаются атрибутами `role` — `banner` для header, `complementary` для aside, `main` для main, `contentinfo` для footer; при нескольких `aside` рекомендуется различать их через `ariaLabel` (например «Боковая навигация», «Связанные ссылки»).
- **Контейнеры прокрутки**: `overflow: auto` у `lh-main` и `lh-aside` на H5 прокручивает сам элемент; **страница Mini Program не имеет прокручиваемого контейнера body** (прокрутка страницы принадлежит корневому узлу `page`), поэтому если поместить всё содержимое страницы непосредственно в `lh-main` в Mini Program, прокрутка элемента и прокрутка страницы могут наложиться и дать двойную полосу прокрутки. Для полностраничной разметки с боковой панелью рекомендуется задать внешней обертке `h: '100vh'`, чтобы `lh-main` прокручивался самостоятельно; либо при необходимости обернуть содержимое в `scroll-view`.
- **Итог переноса**: доступен на всех платформах, поведение идентично версии plus; единственное, о чем стоит помнить, — семантика контейнеров «прокрутка на уровне страницы или элемента» в Mini Program.

::: tip Отличия от версии Vue 3
- Семантические теги заменены на `view` с атрибутами `role` (WXSS запрещает селекторы тегов), семантика доступности сохранена.
- Теги подкомпонентов следуют соглашению easycom: `lh-header` / `lh-aside` / `lh-main` / `lh-footer` (при импорте по необходимости соответствующие имена — `LhHeader` и т. д.).
- Добавлен prop `customClass`: в uni-app обычный класс не проходит сквозь `styleIsolation`, поэтому пользовательские классы передаются через prop (версия plus передает классы напрямую).
- Направление расположения и механизм provide/inject, переключающий на вертикаль при наличии Aside, полностью идентичны версии plus.
:::
