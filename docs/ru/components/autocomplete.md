# Autocomplete

Поле с подсказками, фильтрующее по мере ввода: текстовое поле (combobox) плюс выпадающий список подсказок (listbox).

## Базовое использование

```vue
<script setup>
import { ref } from 'vue'
const value = ref('')
const options = [
  { label: 'Тушь' },
  { label: 'Пустое пространство' },
  { label: 'Печать', value: 'seal' },
]
</script>

<template>
  <lh-autocomplete v-model="value" :options="options" />
</template>
```

Если у опции указан только `label`, отправляемым значением будет сам label; добавьте `value`, когда нужен машиночитаемый идентификатор. Отключённые опции остаются в списке, отображаются серым и не доступны для выбора.

## Фильтрация

По умолчанию подсказки фильтруются по вхождению строки запроса в `label` (без учёта регистра, начальные и конечные пробелы не участвуют в сопоставлении):

```vue
<template>
  <lh-autocomplete v-model="value" :options="options" case-sensitive />
</template>
```

`case-sensitive` включает сопоставление с учётом регистра; передайте `trim` как `false`, чтобы сохранить пробелы в сопоставлении.

## Callback выбора

```vue
<template>
  <lh-autocomplete v-model="value" :options="options" @select="onSelect" />
</template>
```

Событие `select` получает отправляемое значение и исходный объект опции.

## Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue | Вводимое значение (v-model) | `string` | `''` |
| options | Опции подсказок | `LhAutocompleteOption[]` | `[]` |
| caseSensitive | Сопоставление с учётом регистра | `boolean` | `false` |
| trim | Удалять начальные и конечные пробелы строки запроса перед сопоставлением | `boolean` | `true` |
| placeholder | Текст-заполнитель | `string` | — |
| placeholderStyle | Стиль текста-заполнителя (заменяет `::placeholder`) | `string` | — |
| disabled | Отключить компонент | `boolean` | `false` |
| openOnFocus | Открывать панель подсказок при фокусе | `boolean` | `true` |
| ariaLabel | Доступное имя | `string` | — |
| customClass | Пользовательский класс | `string` | — |
| sx | Быстрые свойства макета | `LhSxProps` | — |

## Слоты

| Слот | Описание |
| --- | --- |
| empty | Пустое состояние при отсутствии совпадений (текст по умолчанию берётся из сообщения локали autocomplete.noMatch) |

## Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Записывает значение после ввода или выбора | `(value: string)` |
| change | Вводимое значение изменилось | `(value: string)` |
| select | Выбрана подсказка | `(value: string \| number, option: LhAutocompleteOption)` |

## Методы (defineExpose)

| Метод | Описание |
| --- | --- |
| open / close | Открыть / закрыть панель вручную |
| isOpen | Текущее состояние «открыто/закрыто» (только для чтения) |

## Платформенные различия

| Возможность | H5 | Мини-программа |
| --- | --- | --- |
| Позиционирование выпадающего списка | root-portal + двухкадровое измерение (как у select) | Alipay использует root-portal или фиксированное позиционирование внутри страницы в зависимости от версии базовой библиотеки; Douyin — фиксированное внутри страницы |
| Навигация с клавиатуры / Esc | Стрелки перемещают подсветку, Enter выбирает, Esc закрывает | События клавиатуры отсутствуют; выбор только нажатием |
| Подсветка при наведении (hover) | Есть | Нет (нажатие выбирает сразу) |
| openOnFocus | Открывается при фокусе | Открывается при фокусе |
