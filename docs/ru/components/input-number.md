# InputNumber

Числовое поле ввода: меняйте значение вводом или кнопками увеличения/уменьшения, с ограничением диапазона, шагом, точностью и строгим шагом. Нормализация параметров, шаг и ограничение при фиксации значения полностью обеспечиваются чистыми функциями ядра `@lh-ui/share`.

## Базовое использование

```vue
<template>
  <lh-input-number v-model="value" />
</template>

<script lang="ts" setup>
import { ref } from 'vue'
const value = ref<number | null>(1)
</script>
```

## Ограничение диапазона

`min` / `max` ограничивают и шаг кнопками, и фиксацию введённого значения (значения вне диапазона возвращаются в границы).

```vue
<template>
  <lh-input-number v-model="level" :min="1" :max="10" />
</template>
```

## Шаг и точность

`step` задаёт шаг; `precision` фиксирует количество знаков после запятой (применяется до ограничения); `step-strictly` выравнивает введённое значение по сетке шага (с округлением).

```vue
<template>
  <lh-input-number v-model="value" :step="2" />
  <lh-input-number v-model="value" :precision="2" placeholder="2 знака после запятой" />
  <lh-input-number v-model="value" :step="10" step-strictly placeholder="только кратные 10" />
</template>
```

## Размеры и кнопки управления

`size` переключает small / medium / large; `controls` скрывает кнопки увеличения/уменьшения (только ввод).

```vue
<template>
  <lh-input-number v-model="value" size="small" />
  <lh-input-number v-model="value" size="large" />
  <lh-input-number v-model="value" :controls="false" placeholder="без кнопок" />
</template>
```

## Отключение и имя формы

`disabled` отключает всё целиком (кнопки не нажимаются, ввод недоступен); `name` — имя нативной формы.

```vue
<template>
  <lh-input-number :model-value="5" disabled />
  <lh-input-number v-model="value" name="quantity" />
</template>
```

## Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue / change | Значение зафиксировано (кнопки фиксируют сразу; введённое значение фиксируется при потере фокуса / подтверждении — в те же моменты, что и нативный change в plus) | `(value: number \| null)` |

## Отличия платформ

- **Момент фиксации (модель черновика)**: у компонента input в uni нет нативного события change (в мини-программах есть только input / blur / confirm), поэтому при вводе синхронизируется лишь внутренний черновик, а фиксация происходит один раз при потере фокуса или по confirm (Enter в H5 / кнопка «Готово» клавиатуры в мини-программах) — эквивалентно нативному change в plus, который срабатывает только в момент фиксации (тот же подход, что в React-версии). Одно и то же значение не отправляется дважды (в MP после confirm следует ещё один blur; дедупликация убирает двойные события).
- **Кнопки — самописные view**: `<button>` из plus заменены на `<view role="button">` (у кнопок MP нельзя сбросить стандартные стили), нажатие работает на всех платформах. У view нет псевдокласса `:disabled`, поэтому вид отключённого состояния даёт встроенное правило-фолбэк компонента на тех же токенах.
- **Шаг стрелками клавиатуры — только H5**: ↑ увеличивает / ↓ уменьшает (фиксация по Enter не вешается на keydown — в H5 события keydown и confirm срабатывают одновременно, поэтому фиксация идёт только через confirm во избежание двойной отправки); в мини-программах нет событий клавиатуры, разницы в поведении нет.
- **Стиль placeholder**: правило `::placeholder` из share попадает только в H5-сборку; в мини-программе используется проп `placeholder-style` (цвет-фолбэк из токенов).
- **Связь с валидацией формы не подключена**: plus выводит `aria-invalid` на поле через контекст формы; семейство input в этом пакете не подключает проброс aria из контекста формы, на значения и валидацию это не влияет.

::: tip Отличия от версии Vue 3
- Логика (нормализация параметров, шаг, ограничение precision / min/max / stepStrictly) полностью совпадает с plus (то же ядро share).
- Добавлена проп `customClass`: в uni-app пользовательские классы не проникают сквозь `styleIsolation`, поэтому передаются через проп.
- Момент фиксации введённого значения: см. первый пункт «Отличий платформ» (модель черновика, эквивалент change из plus).
:::
