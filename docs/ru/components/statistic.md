# Statistic статистика

Отображает статистические значения с поддержкой точности, разделителя разрядов, префиксов/суффиксов и огромных чисел в виде строк.

## Базовое использование

```vue
<template>
  <lh-statistic
    title="Годовые посещения"
    :value="2384712"
  />
</template>
```

## Точность и разделитель

`precision` управляет количеством знаков после запятой (с округлением), а `separator` — разделением разрядов (передайте пустую строку, чтобы отключить).

```vue
<template>
  <lh-statistic
    title="Рейтинг"
    :value="4.8471"
    :precision="2"
  />
  <lh-statistic
    title="Номер"
    :value="8899001"
    separator=""
  />
</template>
```

## Префикс и суффикс

```vue
<template>
  <lh-statistic
    title="Оборот"
    :value="128600"
    prefix="¥"
    suffix="юань"
  />
  <lh-statistic
    title="Темп роста"
    :value="12.6"
    :precision="1"
    suffix="%"
  />
</template>
```

## Огромные числа и нечисловой текст

Строковое значение `value` может содержать огромные числа: строки целых чисел, превышающие `Number.MAX_SAFE_INTEGER`, проходят через строковый путь форматирования без преобразования в Number и без потери точности; строки, которые не разбираются как числа, отображаются как есть.

```vue
<template>
  <lh-statistic
    title="Звёзды"
    value="бесчисленные"
  />
  <lh-statistic
    title="Межзвёздное расстояние"
    value="9007199254740993"
  />
</template>
```

## Слоты

Слоты `title` / `prefix` / `suffix` переопределяют одноимённые props.

```vue
<template>
  <lh-statistic :value="1024">
    <template #title>
      <text>Пользовательский заголовок</text>
    </template>
    <template #prefix>
      <text>¥</text>
    </template>
    <template #suffix>
      <text>юань</text>
    </template>
  </lh-statistic>
</template>
```

## Props

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| title | Заголовок значения (отображается над значением) | `string` | — |
| value | Статистическое значение; строка может содержать огромные числа или текст со знаком | `string \| number` | `0` |
| precision | Знаки после запятой | `number` | `0` |
| separator | Разделитель разрядов; пустая строка отключает разделение | `string` | `','` |
| prefix | Префикс значения, например символ валюты | `string` | — |
| suffix | Суффикс значения, например единица измерения | `string` | — |
| customClass | Пользовательское имя класса | `string` | — |
| sx | Быстрые свойства layout | `LhSxProps` | — |

## Slots

| Слот | Описание |
| --- | --- |
| title | Пользовательский заголовок |
| prefix | Пользовательский префикс |
| suffix | Пользовательский суффикс |

## Различия платформ

- Чисто демонстрационный компонент, не использующий никаких платформенных API; поведение полностью идентично на H5 и в WeChat Mini Program.
- Вся логика форматирования (точность, разделение разрядов, строковый путь для огромных чисел) создаётся чистой функцией `formatStatisticValue` из `@lh-ui/share`; этот репозиторий пишет только реактивный клей и никогда не копирует реализацию core.
- Область значения несёт `aria-live="polite"`: на H5 программы чтения с экрана вежливо объявляют новое значение при изменении `value`; поддержка чтения с экрана в Mini Program зависит от возможностей платформы.
- Компонент не содержит анимации счёта (count-up). Если она будет добавлена позже: в Mini Program доступны и `setInterval`, и `requestAnimationFrame`, но `transitionend` там ненадёжен, поэтому окончание анимации нужно выравнивать с помощью `setTimeout` (тот же подход, что и в переходах message / loading).
