# DatePicker (выбор даты)

Средство выбора даты: нажмите на триггер-бокс, чтобы открыть панель-календарь, поддерживающую три режима выбора (дата / месяц / год), пользовательский формат отображения и эхо значений-диапазонов. Алгоритмы сетки календаря, форматирование дат и проверка отключения полностью потребляют чистые функции `@lh-ui/share` core, а панель — это сетка `view`, нарисованная вручную, поэтому рендеринг в H5 и WeChat Mini Program идентичен.

## Контракт типа значения

Привязанное значение **всегда является объектом `Date`** (диапазон — кортеж `[Date, Date]`); компонент не принимает и не отдаёт строки даты в формате ISO:

```vue
<template>
  <lh-date-picker v-model="value" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
// ✅ Правильно: объект Date
const value = ref<Date | null>(new Date(2026, 10, 3))
// ❌ Неправильно: '2026-11-03' не отображается и не разбирается
</script>
```

Проп `format` влияет только на **отображение в триггере и панели** (фиксированные токены `yyyy` / `MM` / `dd` / `HH` / `mm` / `ss`) и никогда не меняет форму привязанного значения. Вы получаете `Date`; для строки ISO при сохранении вызовите `formatDate` или `toISOString()` самостоятельно.

## Базовое использование

```vue
<template>
  <lh-date-picker v-model="value" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date | null>(new Date(2026, 10, 3))
</script>
```

В режиме даты нажатие на день лишь **временно сохраняет** его; нажмите「OK」в нижней части панели, чтобы подтвердить (двухшаговая отправка, как в версии Vue3). Кнопка「Сегодня」возвращает панель на текущий месяц и временно сохраняет текущий день.

## Режимы месяц и год

С `mode="month"` / `mode="year"` панель открывается сразу на соответствующей сетке, а нажатие на ячейку выбирает и закрывает мгновенно (без нижних кнопок). В режиме даты нажатие на заголовок панели позволяет drill-down по уровням: дата → месяц → год; в режиме года нажатие на заголовок возвращает к месяцам.

```vue
<template>
  <lh-date-picker v-model="month" mode="month" />
  <lh-date-picker v-model="year" mode="year" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const month = ref<Date | null>(new Date(2026, 5, 1))
const year = ref<Date | null>(new Date(2024, 0, 1))
</script>
```

## Форматирование даты

```vue
<template>
  <lh-date-picker v-model="value" format="MM/dd/yyyy" />
  <lh-date-picker v-model="value" format="yyyy-MM-dd" />
</template>
```

Если `placeholder` опущен, текст-заполнитель генерируется из `format` (`yyyy` →「год」из языкового пакета, `MM` →「месяц」, `dd` →「день」).

## Отключено и только для чтения

```vue
<template>
  <lh-date-picker v-model="value" disabled />
  <lh-date-picker :model-value="value" readonly />
</template>
```

`disabled` отключает весь компонент (панель не открывается по нажатию); `readonly` — только для чтения (принимает программные значения, но никогда не открывает панель).

## Размеры и очистка

```vue
<template>
  <lh-date-picker v-model="value" size="small" />
  <lh-date-picker v-model="value" size="medium" />
  <lh-date-picker v-model="value" size="large" />
  <lh-date-picker v-model="value" :clearable="false" />
</template>
```

`size` возвращается к глобальному размеру ConfigProvider, а в конечном итоге — к `medium`. `clearable` включён по умолчанию и показывает значок очистки справа от триггера.

## Эхо значений-диапазонов

Когда привязанное значение — `[Date, Date]`, триггер отображает оба конца, соединённые через `range-separator` (по умолчанию `~`):

```vue
<template>
  <lh-date-picker v-model="span" range-separator=" до " />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const span = ref<[Date, Date]>([new Date(2026, 10, 1), new Date(2026, 10, 7)])
</script>
```

::: warning UI выбора диапазона / даты-времени ещё не реализован
Как и в версии Vue3, `mode="datetime"` и выбор диапазона — **только резервирование типа, без UI выбора** (колонки времени и панель диапазона не реализованы, отставание семейства P-08). Значение-диапазон может отображаться, но нажатие「OK」внутри панели никогда не перезаписывает уже привязанный диапазон одиночным `Date`.
:::

## Кастомизация ячеек и панели

```vue
<template>
  <lh-date-picker v-model="value" :cell-class-name="cellClassName" popper-class="my-popper" />
</template>

<script setup lang="ts">
const cellClassName = (date: Date) => (date.getDay() === 0 || date.getDay() === 6 ? 'my-weekend' : '')
</script>
```

`cell-class-name` добавляет пользовательский класс для каждого дня (пустые возвращаемые значения пропускаются); `popper-class` пробрасывается в корень панели для стилизации на уровне панели.

## DatePicker API

### Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue | Привязанное значение (Date / кортеж диапазона / null, **без строк ISO**) | `Date \| [Date, Date] \| null` | `null` |
| mode | Режим выбора | `'date' \| 'month' \| 'year' \| 'datetime' \| 'range'` | `'date'` |
| size | Размер (возвращается к глобальному размеру ConfigProvider, затем medium) | `'small' \| 'medium' \| 'large' \| 'mini' \| 'x-large'` | `'medium'` |
| disabled | Отключить весь компонент | `boolean` | `false` |
| clearable | Показывать кнопку очистки | `boolean` | `true` |
| placeholder | Текст-заполнитель (генерируется из format, если опущен) | `string` | `''` |
| format | Формат отображения (фиксированные токены, только отображение) | `string` | `'yyyy-MM-dd'` |
| readonly | Только для чтения (никогда не открывает панель) | `boolean` | `true` |
| rangeSeparator | Разделитель диапазона (соединяет эхо диапазона) | `string` | `'~'` |
| cellClassName | Колбэк пользовательского класса ячейки дня | `(date: Date) => string` | — |
| popperClass | Пользовательский класс панели | `string` | — |
| customClass | Пользовательский класс корневого узла | `string` | — |
| themeVars | Переменные темы на уровне компонента, переопределяют ConfigProvider | `Record<string, string>` | — |
| sx | Пропы быстрой раскладки (корневой узел; плавающая панель не затрагивается) | `LhSxProps` | — |

::: tip Значения mode
`'datetime'` и `'range'` — **резервирование типов**: `LhDatePickerMode` (share core) их включает, но колонки времени и панель диапазона не реализованы (отставание P-08); пока используйте только `'date'` / `'month'` / `'year'`.
:::

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Значение изменилось (v-model) | `(value: Date \| [Date, Date] \| null)` |
| change | Значение подтверждено (та же нагрузка, что у update:modelValue) | `(value: Date \| [Date, Date] \| null)` |

### Доступность

- Триггер — `role="combobox"` (`aria-expanded` / `aria-haspopup="dialog"` / `aria-controls` указывает на панель); пакет атрибутов создаёт функция share `getDatePickerTriggerAria`
- Панель — `role="dialog"`; календарь — `role="grid"`, ячейки дней — `role="gridcell"`, несущие `aria-selected` / `aria-current="date"` (сегодня) / `aria-disabled` (отключено)
- `aria-label` ячейки дня — полный текст「YYYY год, месяц M, день D, день недели X」для экранных дикторов
- Кнопки перелистывания месяцев — `role="button"` + `aria-label` (ключи языка `datepicker.prevMonth` / `datepicker.nextMonth`)
- Навигация по сетке клавиатурой и клавиатурное поведение триггера доступны только в H5 — см. платформенные различия ниже

::: tip Платформенные различия (отличия от версии Vue3)
- **Выбор через панель**: календарная панель plus изначально панельная (а не колесо прокрутки), и этот порт сохраняет то же взаимодействие; плавающий слой поддерживается `lh-root-portal` вместо `Teleport to="body"` (с внутристраничным fallback `fixed` для старых версий), позиционирование идёт через асинхронное двухкадровое измерение (скрытый рендер для замера → `computePosition` → показ, без мерцания), переходы входа/выхода не подключены.
- **Отображение элементов**: `<div>` / `<button>` / `<input>` из plus заменены на `<view>`; эхо и заполнитель триггера рисуются вручную через `<text>` (MP не поддерживает `::placeholder`, цвет заполнителя даёт инлайн-модификатор класса в SFC с тем же токеном), а отключенные состояния кнопок месяц / сегодня / OK несутся классами (у `view` нет псевдокласса `:disabled`).
- **Закрытие по клику снаружи**: plus слушает document-level click; этот порт закрывает по нажатию на прозрачный внутристраничный маски (эквивалентная семантика, в MP нет document), причём нажатие на маску только закрывает и не эммитит change.
- **Клавиатурная навигация только H5**: Enter / Space на триггере, перемещения стрелками по сетке (включая перелистывание месяцев) / Home / End / PageUp / PageDown, roving tabindex и Escape, закрывающий верхний оверлей — в MP нет клавиатурных событий, поэтому защищённый условной компиляцией код не вызывается, а в MP-бандле нет мёртвого кода.
- **aria-атрибуты bindятся по одному**: пакет share `LhAriaAttrs` нельзя развернуть через `v-bind` (компилятор шаблонов MP не поддерживает), поэтому слой-клей разворачивает ключи `aria-*` в явные привязки; контракт по-прежнему определяют чистые функции share.
- **Контракт типа значения**: идентичен plus — привязанное значение это `Date` / `[Date, Date]` и никогда строка даты ISO в обе стороны; `format` влияет только на слой отображения.
:::
