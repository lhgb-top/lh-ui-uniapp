# Calendar Календарь

Компонент календаря, отображающий дни в месячной сетке. Поддерживаются три режима выбора — одиночный, диапазон (начало и конец) и множественный — а также ограничение `range` выбираемого диапазона. Все тексты (заголовки дней недели, названия месяцев и заголовок панели) берутся из ключей локали `datepicker.weeks.*` / `datepicker.month1~12` / `datepicker.panelTitle`. Календарь — сетка, нарисованная средствами `view`, без каких-либо нативных элементов выбора даты, поэтому он естественно дружелюбен к мобильным устройствам и доступен на всех платформах.

## Базовое использование

```vue
<template>
  <lh-calendar v-model="value" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<Date>()
</script>
```

Без `modelValue` компонент хранит состояние выбора внутри себя; при передаче он становится управляемым (как и все компоненты форм).

## Выбор диапазона

При `selection="range"` первый клик фиксирует дату начала (значение становится `[начало, начало]`), второй — дату конца с автоматической нормализацией (клик в обратном порядке также даёт `[раньше, позже]`):

```vue
<template>
  <lh-calendar v-model="span" selection="range" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const span = ref<Date[]>([])
</script>
```

Оба конца получают стиль `--selected`, а дни между ними — цвет фона интервала `--in-range` (концы не включаются).

## Ограничение выбираемого диапазона

`range` принимает кортеж `[начало, конец]`; дни вне интервала отключаются (проверку выполняет чистая функция из share, а перевёрнутые диапазоны нормализуются автоматически):

```vue
<template>
  <lh-calendar v-model="value" :range="[start, end]" />
</template>

<script setup lang="ts">
const start = new Date(2026, 10, 1)
const end = new Date(2026, 10, 30)
</script>
```

## Множественный выбор

При `selection="multiple"` повторный клик по уже выбранному дню снимает выделение, а результат остаётся отсортированным по времени:

```vue
<template>
  <lh-calendar v-model="dates" selection="multiple" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const dates = ref<Date[]>([])
</script>
```

## Режим триггера input

При `mode="input"` рисуется только триггер-бокс; нажмите его, чтобы развернуть или свернуть панель, которая закрывается после выбора (`close-on-select` включён по умолчанию; для диапазона нужно два клика):

```vue
<template>
  <lh-calendar v-model="value" mode="input" placeholder="Выберите дату" />

  <!-- Диапазон + без автоматического закрытия -->
  <lh-calendar v-model="span" mode="input" selection="range" :close-on-select="false" />
</template>
```

Текст триггер-бокса по умолчанию `YYYY-MM-DD` (для диапазона `начало ~ конец`); текст-заполнитель берётся из ключа локали `select.placeholder`.

## Несколько панелей и пользовательский контент

`panels` задаёт количество одновременно отображаемых месячных панелей (в flex-строках с переносом), а слоты `header` и `cell` настраивают заголовок панели и ячейки дней:

```vue
<template>
  <lh-calendar v-model="value" :panels="2">
    <template #header="{ year, month }">
      <view class="my-title">{{ year }} / {{ month + 1 }}</view>
    </template>
    <template #cell="{ date }">
      <view class="my-cell">{{ date.getDate() }}</view>
    </template>
  </lh-calendar>
</template>
```

::: tip Дружелюбность к мобильным
Панель календаря — чистая сетка `view` (семь равных столбцов), без нативного picker и без измерений DOM;
H5 и Mini-Program WeChat отрисовывают её одинаково, а на узких экранах она подстраивается под ширину контейнера.
:::

## Calendar API

### Props

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| modelValue | Текущий выбор (управляемый v-model; при отсутствии — внутреннее состояние) | `Date \| Date[]` | — |
| selection | Режим выбора: одиночный / диапазон / множественный | `'single' \| 'range' \| 'multiple'` | `'single'` |
| range | Ограничение выбираемых дат (вне диапазона отключено, перевёрнутые нормализуются) | `[Date, Date]` | — |
| mode | Форма отображения: постоянная панель / разворачиваемый триггер-бокс | `'panel' \| 'input'` | `'panel'` |
| panels | Количество одновременно отображаемых месячных панелей | `number` | `1` |
| placeholder | Текст-заполнитель в режиме input (по умолчанию ключ локали select.placeholder) | `string` | — |
| closeOnSelect | Сворачивать ли панель после выбора в режиме input | `boolean` | `true` |
| customClass | Пользовательский класс, передаваемый корневому узлу | `string` | — |
| sx | Свойства быстрой раскладки (применяются к корневому узлу) | `LhSxProps` | — |

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Изменение выбора (v-model) | `(value: Date \| Date[])` |
| change | Изменение выбора (та же нагрузка, что у update:modelValue) | `(value: Date \| Date[])` |
| select | При клике по дню (отключённые дни игнорируются) | `(date: Date)` |

### Slots

| Слот | Описание | Параметры области |
| --- | --- | --- |
| header | Настройка заголовка панели | `{ year: number, month: number }` (month с 0) |
| cell | Настройка ячейки дня | `{ date: Date }` |

### Доступность

- Сетка имеет `role="grid"`, строки `role="row"`, ячейки дней `role="gridcell"` и заголовки `role="columnheader"`, а также `aria-selected` / `aria-current="date"` (сегодня) / `aria-disabled` (отключено)
- `aria-label` каждой ячейки — строка `YYYY-MM-DD` для скринридеров
- Кнопки смены месяца — `role="button"` + `aria-label` (ключи локали `datepicker.prevMonth` / `datepicker.nextMonth`)
- Навигация по сетке клавиатурой (стрелки, Home / End, PageUp / PageDown) работает только в H5 — см. платформенные различия ниже

::: tip Платформенные различия (отличия от версии Vue3)
- **Носитель сетки**: календарь — сетка из семи столбцов, нарисованная через `view` (WXSS `grid-template-columns: repeat(7, 1fr)`), без нативных элементов выбора даты; H5 и Mini-Program WeChat отрисовывают его и ведут себя идентично, оставаясь естественно мобильными.
- **Отображение элементов**: `<div>` / `<button>` / `<input>` из plus заменены на `<view>`; триггер-бокс в режиме input рисуется через `view` и сам отображает текст-заполнитель и выбранное значение (MP не поддерживает `::placeholder`, а нативный `<input>` потребовал бы дополнительного `placeholder-style`). Отключённые ячейки несут класс `--disabled` (у `view` нет псевдокласса `:disabled`; SFC добавляет инлайновый запасной вариант с тем же токеном).
- **Клавиатурная навигация только в H5**: стрелки / Home / End / PageUp / PageDown и roving tabindex не имеют клавиатурных событий в MP, поэтому код вообще не вызывается благодаря условной компиляции — в бандле MP нет мёртвого кода.
- **Закрытие по клику вне только в H5**: plus слушает document-level mousedown для сворачивания панели; в MP нет document, поэтому панель переключается нажатием триггер-бокса.
- **aria-атрибуты связываются по одному**: пакет `LhAriaAttrs` из share нельзя развернуть через `v-bind` (компилятор шаблонов MP не поддерживает это), поэтому слой-связка разворачивает ключи `aria-*` в явные привязки; контракт по-прежнему определяют чистые функции share.
:::
