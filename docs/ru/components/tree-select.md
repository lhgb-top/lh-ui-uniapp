# TreeSelect (древовидный выбор)

Древовидный селектор для иерархических данных — например, организационных структур или деревьев категорий. Клик по триггеру открывает панель дерева; в режиме одиночного выбора клик по узлу выбирает его и закрывает панель, в режиме множественного выбора отметка делается через флажки (каскадирование родитель-потомок).

## Базовое использование

```vue
<template>
  <lh-tree-select v-model="value" :data="data" placeholder="请选择节点" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<string | undefined>(undefined)
const data = [
  {
    key: 'zhinan',
    label: '指南',
    children: [
      {
        key: 'sheji',
        label: '设计指南',
        children: [
          { key: 'yuansze', label: '颜色' },
          { key: 'fuziyuanze', label: '字体' },
        ],
      },
      { key: 'shejiguize', label: '设计规则' },
    ],
  },
  {
    key: 'zujian',
    label: '组件',
    children: [
      { key: 'jiben', label: '基础' },
      { key: 'fankui', label: '反馈' },
    ],
  },
]
</script>
```

Клик по узлу выбирает его (включая нелистовые узлы) и закрывает панель; клик по стрелке разворачивания слева от узла только разворачивает / сворачивает его, не изменяя значение выбора. Триггер отображает `label` выбранного узла.

## Множественный выбор

```vue
<template>
  <lh-tree-select v-model="value" :data="data" multiple placeholder="请选择多个节点" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<string[]>(['jiben', 'fankui'])
const data = [
  {
    key: 'zujian',
    label: '组件',
    children: [
      { key: 'jiben', label: '基础' },
      { key: 'fankui', label: '反馈' },
    ],
  },
]
</script>
```

В режиме множественного выбора `v-model` привязан к массиву отмеченных ключей (`string[]`) с каскадированием родитель-потомок: отметка родительского узла автоматически отмечает всех доступных для отметки потомков, родитель становится полностью отмеченным, когда отмечены все его потомки, и частично отмеченным (indeterminate), когда отмечена их часть. Клик по подписи узла только разворачивает его, отметка выполняется через флажок (как в версии Vue3). Триггер отображает метки всех отмеченных ключей, соединённые символом「、」.

## Отключение

`disabled: true` в данных узла отключает этот узел (клик не разворачивает и не выбирает его, а его флажок недоступен для клика); prop `disabled` отключает весь селектор.

```vue
<template>
  <lh-tree-select v-model="value" :data="disabledData" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref<string | undefined>(undefined)
const disabledData = [
  {
    key: 'zhinan',
    label: '指南',
    children: [
      {
        key: 'sheji',
        label: '设计指南',
        disabled: true,
        children: [{ key: 'yuansze', label: '颜色' }],
      },
      { key: 'shejiguize', label: '设计规则' },
    ],
  },
]
</script>
```

## API TreeSelect

### Props

| Prop | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue | Привязанное значение (`string` для одиночного / `string[]` для множественного выбора, контролируемый v-model) | `string \| string[] \| undefined` | — |
| data | Данные дерева | `LhTreeNode[]` | `() => []` |
| multiple | Множественный выбор (показываются флажки, значение — массив отмеченных ключей, каскадирование родитель-потомок) | `boolean` | `false` |
| disabled | Отключает весь селектор | `boolean` | `false` |
| placeholder | Заполнитель (если не передан, берётся из языкового пакета `select.placeholder`) | `string` | — |
| customClass | Пользовательский класс (пробрасывается в корневой узел) | `string` | — |
| themeVars | Переменные темы на уровне компонента | `Record<string, string>` | — |
| sx | Свойства быстрой разметки sx (применяются к корневому элементу триггера, плавающая панель не затрагивается) | `LhSxProps` | — |

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Срабатывает при изменении привязанного значения | `(value: string \| string[] \| undefined)` |
| change | Срабатывает при изменении выбора | `(value: string \| string[] \| undefined)` |

### Структура данных

Определение типа `LhTreeNode` (источник истины — `@lh-ui/share/core/tree`):

```ts
interface LhTreeNode {
  /** Уникальный ключ */
  key: string
  /** Отображаемый текст */
  label: string
  /** Дочерние узлы */
  children?: LhTreeNode[]
  /** Отключён */
  disabled?: boolean
  /** Листовой ли узел (выводится из children, если не передано) */
  isLeaf?: boolean
}
```

### Доступность

- Триггер несёт `aria-haspopup="tree"` / `aria-expanded` / `aria-label` (из языкового пакета `treeSelect.triggerLabel`)
- Панель — `role="listbox"`, встроенное дерево — `role="tree"`, узлы — `role="treeitem"` с `aria-level` / `aria-expanded` / `aria-selected` / `aria-disabled`; при множественном выборе панель несёт `aria-multiselectable`, а флажки — `role="checkbox"` с `aria-checked` (`mixed` для частичной отметки)
- Отступы уровней, поворот стрелки разворачивания и трёхсостоятельный вид флажка берутся из источника стилей share (`@lh-ui/share/styles/tree`), дублирования стилей на стороне пользователя нет

::: tip Платформенные различия (отличия от версии Vue3)
- **Композиция-клей вместо отдельного core**: в share core нет модуля tree-select; данная сторона повторяет форму реализации plus и компонует «триггер select + панель lh-tree» — панель встраивает `lh-tree`, а вся логика дерева (развёртывание / выбор / каскадирование отметок) потребляется из чистых функций `core/tree` (`flattenTree` / `toggleCheckKeys` / `getNodeCheckState` и др.), ничего не копируется. API и события выровнены по plus, новые возможности на этой стороне не добавлены.
- **Плавающая панель**: plus монтирует панель в `Teleport to="body"`; на uni-app её несёт `lh-root-portal` (на старых базовых библиотеках — fallback с fixed внутри страницы), а позиционирование идёт через двухкадровое асинхронное измерение (скрытый рендер для замера → `computePosition` → показ, против мерцания). Расчёт положения асинхронен — не предполагайте синхронный результат.
- **Прокрутка панели дерева**: в scss из share `.lh-tree-select__panel` используется `overflow: auto`, но у `view` в MP нет надёжного скролла при переполнении, поэтому панель оборачивает дерево в `scroll-view` (`scroll-y`) для вертикальной прокрутки, а максимальная высота выровнена с значением share 320px.
- **Клавиатурная навигация не включена**: закрытие по Escape и слушатель на уровне документа в plus опираются на события клавиатуры, которых нет в Mini Program; на этой стороне панель закрывается тапом по прозрачной странице-маске (как у select / cascader), деградации через условную компиляцию нет.
- **prop `teleported` не перенесён**: plus управляет им, чтобы монтировать панель на body; на uni-app оверлей всегда идёт через `lh-root-portal`, поэтому такой семантики не существует.
- **Закрытие по клику вне**: plus слушает клики по document через `useLhClickOutside`; uni-app использует прозрачную маску внутри страницы (клик по маске закрывает).
- **Управляемое состояние отметок исправлено**: plus не передаёт `checked-keys` во встроенное дерево, поэтому предустановленное значение множественного выбора не отражается на флажках; данная сторона также передаёт `v-model` как `checked-keys`, так что и флажки, и эхо триггера управляются `v-model` (API не изменился).
- **Нет авто-закрытия при уходе триггера из области просмотра**: у uni-app нет единого канала слежения за скроллом / изменением размера, поэтому не перенесено.
:::
