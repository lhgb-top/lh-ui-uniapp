# Image

Изображение с заглушкой при ошибке загрузки и опциональным предпросмотром по нажатию
(через нативный API `uni.previewImage`, доступный на всех платформах). Режим кадрирования
отображается на `mode` компонента `<image>` uni, ленивая загрузка использует встроенную
`lazy-load`. Нормализация списка предпросмотра и имена классов состояния дают чистые
функции ядра `@lh-ui/share`.

## Базовое использование

```vue
<template>
  <lh-image src="https://picsum.photos/240/140" alt="Пример изображения" :sx="{ w: '240px', h: '140px' }" />
</template>
```

`alt` обязателен на уровне TS — изображение без альтернативного текста не пройдёт.
`<image>` в uni по умолчанию имеет размер 320×240 — задавайте размеры явно через `w` / `h`
в `sx` (или style); скругление углов встроено в источник стилей share
(`--lh-border-radius-small`) и не требует настройки.

## Режимы заполнения

`fit` описывает семантику object-fit из CSS и отображается на `mode` компонента `<image>` uni:
`contain` → `aspectFit`, `cover` → `aspectFill`, `fill` → `scaleToFill`.

```vue
<template>
  <lh-image src="https://picsum.photos/240/140" alt="Обрезка с покрытием" fit="cover" :sx="{ w: '110px', h: '80px' }" />
  <lh-image src="https://picsum.photos/240/140" alt="Полный показ" fit="contain" :sx="{ w: '110px', h: '80px' }" />
  <lh-image src="https://picsum.photos/240/140" alt="Растяжение" fit="fill" :sx="{ w: '110px', h: '80px' }" />
</template>
```

::: tip none / scale-down — приблизительные отображения
`none` отображается на `center` (без масштабирования, показывается только центральная область —
та же семантика, что у object-fit: none); в uni нет режима, эквивалентного `scale-down`,
поэтому берётся ближайшее по смыслу `aspectFit` (то же зарегистрированное отклонение,
что и в lh-avatar).
:::

## Ленивая загрузка

`lazy` включает встроенную `lazy-load` компонента `<image>` uni (загрузка при входе в область просмотра).

```vue
<template>
  <scroll-view scroll-y style="height: 140px; width: 100%">
    <lh-image
      v-for="i in 4"
      :key="i"
      :src="`https://picsum.photos/240/120?random=${i}`"
      :alt="`Ленивое изображение ${i}`"
      lazy
      :sx="{ w: '240px', h: '120px', mb: 1 }"
    />
  </scroll-view>
</template>
```

В WeChat `lazy-load` действует только для изображений внутри page и scroll-view.

## Ошибка загрузки

При ошибке загрузки компонент переключается на заглушку (к корневому узлу добавляется
`lh-image--error`). Текст по умолчанию берётся из ключа локали `image.error`
(девять языков) и переопределяется слотом `error`; одновременно генерируется событие `error`.

```vue
<template>
  <lh-image src="https://invalid.example.com/not-found.png" alt="Заглушка по умолчанию" :sx="{ w: '240px', h: '140px' }" />
  <lh-image src="https://invalid.example.com/not-found.png" alt="Своя заглушка" :sx="{ w: '240px', h: '140px' }">
    <template #error>Своя заглушка</template>
  </lh-image>
</template>
```

## Предпросмотр по нажатию

При включённом `preview` нажатие на изображение открывает нативный предпросмотр
`uni.previewImage` (доступен на всех платформах); список изображений передаётся через
`preview-src-list`, а при его отсутствии список сводится к `[src]` (та же нормализация,
что в plus, начальный индекс зафиксирован на 0).

```vue
<template>
  <lh-image
    src="https://picsum.photos/240/140"
    alt="Предпросмотр нескольких изображений"
    preview
    :preview-src-list="[
      'https://picsum.photos/600/400?random=1',
      'https://picsum.photos/600/400?random=2',
      'https://picsum.photos/600/400?random=3',
    ]"
    :sx="{ w: '240px', h: '140px' }"
  />
  <lh-image src="https://picsum.photos/240/140" alt="Предпросмотр одного изображения" preview :sx="{ w: '140px', h: '140px' }" />
</template>
```

## Props

| Свойство | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| src | Адрес изображения | `string` | — |
| alt | Альтернативный текст (строгое требование a11y, обязательно на уровне TS) | `string` | — |
| fit | Режим кадрирования (отображается на mode изображения uni) | `'contain' \| 'cover' \| 'fill' \| 'none' \| 'scale-down'` | `'cover'` |
| preview | Открывает ли нажатие предпросмотр | `boolean` | `false` |
| preview-src-list | Список предпросмотра (при отсутствии сводится к [src]) | `string[]` | — |
| lazy | Ленивая загрузка (нативная lazy-load изображения uni) | `boolean` | `false` |
| customClass | Пользовательское имя класса (пробрасывается в корневой узел) | `string` | — |
| sx | Быстрые свойства раскладки | `LhSxProps` | — |

## Events

| Событие | Описание | Параметры callback |
| --- | --- | --- |
| load | Срабатывает при успешной загрузке изображения | `(event: Event)` |
| error | Срабатывает при ошибке загрузки (переключение на заглушку) | `(event: Event)` |

## Slots

| Слот | Описание |
| --- | --- |
| error | Содержимое заглушки при ошибке (по умолчанию ключ локали image.error) |

## Отличия платформ

- **Предпросмотр идёт через нативный API `uni.previewImage`** (доступен на всех платформах):
  в plus предпросмотр — это самостоятельно нарисованное окно-просмотрщик (teleport в body,
  масштаб / поворот / переключение нескольких изображений / закрытие по Esc / ловушка фокуса),
  которое невозможно перенести в мини-программу из-за отсутствия document. Версия uniapp
  вместо этого вызывает `uni.previewImage` — на H5 слой обеспечивает среда uni, в WeChat
  используется нативная страница предпросмотра; взаимодействие предоставляет платформа,
  **возможности настройки нет** (прозрачность маски / кнопка закрытия / панель инструментов).
  Самостоятельный компонент `LhImageViewer` из plus в этом репозитории не поставляется.
- **Отображение fit → mode**: `contain` / `cover` / `fill` отображаются на `aspectFit` /
  `aspectFill` / `scaleToFill`; `none` — на `center`; для `scale-down` эквивалента нет,
  берётся ближайшее по смыслу `aspectFit` (то же зарегистрированное отклонение, что и в
  lh-avatar). CSS-реализация object-fit работает только с настоящей `<img>` на H5;
  `<image>` в uni на всех платформах управляется через `mode`.
- **Ленивая загрузка**: `<image>` в uni несёт встроенную `lazy-load` (вместо
  `loading="lazy"` в plus); в WeChat действует только для изображений внутри page и
  scroll-view.
- **Размеры и скругление**: `<image>` в uni по умолчанию 320×240, размеры задаются через
  `sx` / style; скругление встроено в источник стилей share (`--lh-border-radius-small`).
  В plus тоже нет пропсов width / height / radius (размеры через sx, скругление через
  источник стилей) — здесь от себя ничего не добавляется.
- **alt**: у `<image>` в мини-программах нет понятия alt (на H5 передаётся как атрибут),
  поэтому резерв доступности слабее, чем у `<img alt>` в вебе; обязательность на уровне TS
  сохранена.
- **Остатки стилей просмотрщика**: источник стилей share содержит правила `.lh-image-viewer*`
  (стили самостоятельно нарисованного просмотрщика plus); согласно ограничению единого
  источника стилей они попадают в продукт style.css этого компонента, не имея узлов ни на
  одной из платформ (безвредная избыточность, по-прежнему в рамках белого списка WXSS:
  семейство `:hover` / `:focus` обёрнуто условной компиляцией только для H5).

::: tip Отличия от версии Vue 3
- Семантика логики (нормализация списка предпросмотра, состояние загрузки, имена классов)
  полностью совпадает с plus (то же ядро share).
- Предпросмотр заменён с самостоятельно нарисованного окна-просмотрщика на нативный API
  `uni.previewImage` (см. «Отличия платформ»).
- Добавлен проп `customClass`: пользовательские имена классов не могут пробить
  styleIsolation в uni-app, поэтому передаются через проп.
- `none` / `scale-down` — приблизительные отображения в мини-программах
  (см. «Отличия платформ»).
:::
