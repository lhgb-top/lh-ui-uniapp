# Пусто

Заглушка для пустых данных; поставляется с иллюстрацией в стиле тушь (水墨).

## Базовое использование

```vue
<template>
  <lh-empty />
</template>
```

Если `description` не передан, берётся `empty.description` из языкового пакета (на русском — «Нет данных»), и переключение языка в ConfigProvider применяется автоматически.

## Свой текст

```vue
<template>
  <lh-empty description="Краска ещё не просохла — смотреть не на что" />
</template>
```

## Своя картинка

```vue
<template>
  <lh-empty image="https://placeholder.invalid/empty.png" description="Совершенно пусто" />
</template>
```

## Своя отрисовка через слот

Слот по умолчанию полностью заменяет стандартную иллюстрацию (при переданном `image` стандартная иллюстрация тоже не рендерится).

```vue
<template>
  <lh-empty description="Нет избранных">
    <view class="my-illustration">🎨</view>
  </lh-empty>
</template>
```

## Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| description | Текст описания пустого состояния (если не передан — из языкового пакета empty.description) | `string` | — |
| image | URL своей картинки (заменяет стандартную иллюстрацию) | `string` | — |
| customClass | Пользовательский класс | `string` | — |
| sx | Быстрые свойства раскладки | `LhSxProps` | — |

## Slots

| Слот | Описание |
| --- | --- |
| default | Своя иллюстрация (после передачи заменяет стандартную) |

::: tip Стандартная иллюстрация на платформе Mini Program
На H5 сохраняется инлайн SVG-иллюстрация (тематичная раскраска без потерь); Mini Program не поддерживает svg, поэтому стандартная иллюстрация рисуется упрощённая, на CSS: цвета берутся из переменных темы, светлая и тёмная темы подхватываются автоматически.
:::
