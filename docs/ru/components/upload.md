# Upload Загрузка файлов

Выбор файлов и их загрузка. Проверка выбора (accept / maxSize / maxCount), конечный
автомат элемента файла (ready → uploading → success / fail) и логика обновления
списка полностью потребляются из чистых функций core `@lh-ui/share`
(`normalizeUploadAccept` / `isFileRejected` / `exceedsMaxSize` /
`exceedsMaxCount` / `patchUploadFile` и др.); слой компонента отвечает только за
рендеринг, события и платформенную адаптацию выбора. Загрузка не содержит
встроенного HTTP-клиента: проп `request` принадлежит потребителю и может быть
сгенерирован через `createLhUploadRequest` адаптера.

## Базовое использование

```vue
<template>
  <lh-upload :request="request" accept="image/*" @success="onSuccess" />
</template>

<script setup lang="ts">
import { createLhUploadRequest } from '@lh-ui/uniapp/src/adapter/upload'

// Мини-программа: uni.uploadFile; H5: XHR + FormData; имя поля по умолчанию
// file. На реальном устройстве целевой домен должен быть зарегистрирован в
// настройках «Серверные домены - uploadFile» WeChat.
const request = createLhUploadRequest('https://upload.example.com/file')

function onSuccess(file: { uid: string; name: string; url?: string }) {
  console.log(file.url)
}
</script>
```

Клик по триггерной области открывает нативный выбор (chooseMedia / chooseImage /
chooseVideo). Когда файл попадает в список, немедленно вызывается `request`: во
время загрузки отображается прогресс-бар, при успехе — ✓ и URL сервера, при неудаче
— причина (событие `error` несёт неудачный файл и строку причины). Если `request`
не передан, компонент только выбирает и проверяет локально: список остаётся в
состоянии `ready`, а канал загрузки потребитель организует сам.

По умолчанию триггерная область выводит текст подсказки («Выбрать файл» или, в
режиме drag, «Перетащите файлы сюда или нажмите для загрузки»; тексты берутся из
ключей `upload.*` share locales, доступны на десяти языках). Передайте слот по
умолчанию, чтобы настроить содержимое триггера.

## Множественный выбор и ограничения количества / размера

```vue
<template>
  <lh-upload
    :request="request"
    accept="image/*"
    multiple
    :max-count="3"
    :max-size="2 * 1024 * 1024"
  />
</template>
```

`multiple` включает множественный выбор в нативном подборщике; после достижения
`maxCount` дальнейший выбор выводит «Превышено ограничение количества» и
прекращает добавление; файлы сверх `maxSize` пропускаются с сообщением «Файл
превышает ограничение размера» (по умолчанию 5 МБ). Оба сообщения выводятся в узле
текста ошибки под списком (`role="alert"`).

## Ограничение типа через accept

```vue
<template>
  <lh-upload :request="request" accept=".png,.jpg" />
</template>
```

`accept` принимает массив `['.png', 'image/*']` или строку через запятую
`'.png,.jpg'`. О том, как правила отображаются на стороне uni, см. «Платформенные
отличия» ниже: панель нативного подборщика умеет фильтровать только по типу
медиа, поэтому правила расширений до панели не доходят и применяются после выбора
функцией `isFileRejected` как резервная проверка.

## Перетаскивание (только H5)

```vue
<template>
  <lh-upload :request="request" accept="image/*" drag multiple />
</template>
```

`drag` превращает триггерную область в зону сброса (`dragover` / `dragleave` /
`drop` работают на H5; сброшенные File оборачиваются в `LhUniFile` и проходят тот
же поток). В мини-программе нет HTML5 drag and drop, поэтому `drag` на MP не
работает, а триггерная область вырождается в загрузку по клику.

## Отключение

```vue
<template>
  <lh-upload :request="request" accept="image/*" disabled />
</template>
```

`disabled` отключает загрузку целиком: клики по триггерной области и активация с
клавиатуры (Enter / Space, только H5) подавляются, а область выводит
`aria-disabled`.

## API

### Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| multiple | Разрешить множественный выбор | `boolean` | `false` |
| drag | Зона перетаскивания (только H5: в MP нет HTML5 drag and drop) | `boolean` | `false` |
| disabled | Отключить | `boolean` | `false` |
| accept | Допустимые расширения / MIME: массив `['.png', 'image/*']` или строка через запятую `'.png,.jpg'` | `string[] \| string` | `[]` |
| maxSize | Ограничение размера одного файла (байт) | `number` | `5242880` (5 МБ) |
| maxCount | Ограничение количества (0 = без ограничения) | `number` | `0` |
| request | Функция запроса загрузки (без неё — только локальный выбор и проверка) | `LhUniUploadRequest` | — |
| customClass | Пользовательский класс (передаётся в корневой узел) | `string` | — |
| sx | свойства быстрой вёрстки sx | `LhSxProps` | — |

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| change | Список файлов изменился (после выбора / завершения загрузки / удаления) | `(files: LhUploadFile[])` |
| success | Один файл загрузился успешно | `(file: LhUploadFile)` |
| error | Один файл не удалось загрузить | `(file: LhUploadFile, reason: string)` |
| remove | Файл удалён | `(uid: string)` |

### Slots

| Имя | Описание |
| --- | --- |
| default | Содержимое триггерной области (по умолчанию текст подсказки) |

### LhUploadFile

| Поле | Описание | Тип |
| --- | --- | --- |
| uid | Уникальный идентификатор (генерируется внутри) | `string` |
| name | Имя файла | `string` |
| size | Размер в байтах | `number` |
| status | Состояние | `'ready' \| 'uploading' \| 'success' \| 'fail'` |
| percent | Прогресс загрузки 0-100 | `number` |
| url | URL сервера (при успехе) | `string` |
| error | Причина неудачи | `string` |

### Слой адаптера (`@lh-ui/uniapp/src/adapter/upload`)

| Экспорт | Описание |
| --- | --- |
| `LhUniFile` | Файловый дескриптор на стороне uni: `{ path, name, size, type }` (path — временный путь: blob / data URL на H5, временный путь wxfile:// на WeChat) |
| `LhUniUploadRequest` | Сигнатура функции-пропа request: принимает `{ file: LhUniFile, onProgress }` и возвращает `Promise<LhUploadResult>` |
| `LhUploadResult` | Результат загрузки: `{ url?, data? }` (при отсутствии url data несёт исходный текст ответа для самостоятельного разбора) |
| `LhUploadConfig` | Конфигурация `createLhUploadRequest`: `{ name?, header?, formData? }` |
| `createLhUploadRequest(action, config?)` | Создаёт функцию request: на мини-программе `uni.uploadFile`, на H5 XHR + FormData |
| `chooseLhFiles(options)` | Единый выбор файлов (обычно вызывается из триггерной области, потребителю требуется редко) |
| `wrapLhNativeFile(file)` | Оборачивает реальный File, сброшенный на H5, в `LhUniFile` |

### Доступность

- Триггерная область имеет `role="button"` и `tabindex` (-1 при отключении) и
  выводит `aria-disabled` в отключенном состоянии
- Элементы в процессе загрузки содержат встроенный прогресс-бар с
  `role="progressbar"` + `aria-valuenow`
- Неудачные элементы показывают текст ошибки; сообщение об ошибке под списком
  имеет `role="alert"`
- Кнопка удаления несёт `aria-label` («Удалить» + имя файла)

::: tip Платформенные отличия (отличия от версии Vue3)
- **Выбор файлов идёт через нативные API**: версия Vue3 использует
  `<input type="file">`, а в мини-программе нет ни File, ни input. Выбор
  унифицирован через `chooseLhFiles` адаптера (chooseMedia / chooseImage /
  chooseVideo), и его результат — временный путь к файлу (`LhUniFile`), а не File
  из DOM.
- **accept отображается только на медиатипы**: API выбора uni понимают только
  image / video. Правила `image/*` (или расширения изображений) → выбор
  изображений, `video/*` (или расширения видео) → выбор видео, их смесь или
  отсутствие правил → chooseMedia в смешанном режиме. Правила расширений
  (например, `.png`) нельзя передать в панель нативного подборщика, поэтому их
  применяет `isFileRejected` после выбора; для правил не-медиа (например,
  `.txt`) в мини-программе нет аналога — они отправляются на выбор изображений, а
  затем отбрасываются резервной проверкой. chooseMedia существует только в
  базовой библиотеке WeChat 2.10+; в адаптере есть проверка существования, и при
  её отсутствии он откатывается на chooseImage / chooseVideo.
- **request принимает LhUniFile, а не File из DOM**: `file` в
  `{ file: LhUniFile, onProgress }` — это временный файловый дескриптор. Чтобы
  загружать напрямую через `uni.uploadFile`, создайте request функцией
  `createLhUploadRequest(action, config)` адаптера (на H5 автоматически
  используется XHR + FormData, что выравнивает семантику обеих сторон).
  **Целевой домен uploadFile должен быть зарегистрирован в настройках
  «Серверные домены» платформы WeChat**, иначе запросы с реального устройства
  блокируются; на H5 такого ограничения нет.
- **Перетаскивание доступно только на H5**: в мини-программе нет HTML5 drag and
  drop, поэтому `drag` на MP не работает (триггерная область вырождается в
  загрузку по клику), а обработчики перетаскивания вырезаются условной
  компиляцией (мёртвого кода в бандле MP нет).
- **Активация с клавиатуры только на H5**: Enter / Space открывают выбор только
  на H5; в мини-программе нет событий клавиатуры.
- **Отмена выбора происходит тихо**: отмена нативного выбора (errMsg содержит
  cancel) не записывает сообщение об ошибке и не вызывает событие `error`.
- **Область API остаётся выровненной с исходниками plus**: возможности, которых
  нет в plus (`action` / `headers` / `fileList` / `before-upload`), не
  добавлены; адрес загрузки и подобные настройки живут в функции request,
  принадлежащей потребителю. Согласно соглашениям пакета добавлен `customClass`
  (проброс для изоляции стилей).
:::
