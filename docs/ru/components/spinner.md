# Spinner (Кружок загрузки)

Базовая вращающаяся фигура, обозначающая выполняющееся действие. Её же использует overlay загрузки (сервис LhLoading).

## Базовое использование

Пять размеров: `mini` / `small` / `medium` / `large` / `x-large`. Диаметры задаются единым константным соответствием (`LH_SPINNER_SIZE_PX`) из core `@lh-ui/share` (12 / 16 / 24 / 32 / 40 px).

```vue
<template>
  <lh-spinner />
  <lh-spinner size="mini" />
  <lh-spinner size="small" />
  <lh-spinner size="medium" />
  <lh-spinner size="large" />
  <lh-spinner size="x-large" />
</template>
```

## Пользовательский цвет

`color` принимает любое значение цвета CSS; если его не передать, фигура наследует текущий цвет текста (`currentColor`).

```vue
<template>
  <lh-spinner color="#C4A35A" />
  <lh-spinner color="#5B8C5A" />
  <lh-spinner color="#B5462F" />
</template>
```

## Наследование цвета текста

Без `color` фигура следует цвету текста контейнера, в котором она расположена, что удобно для смешанных с текстом раскладок.

```vue
<template>
  <view class="row">
    <text>Загрузка…</text>
    <lh-spinner size="small" />
  </view>
</template>
```

## Props

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| size | Размер | `'mini' \| 'small' \| 'medium' \| 'large' \| 'x-large'` | `'medium'` |
| color | Цвет вращения (любое значение цвета CSS; по умолчанию наследует currentColor) | `string` | — |
| customClass | Пользовательское имя класса | `string` | — |
| sx | Быстрые свойства layout | `LhSxProps` | — |

## Различия платформ

- **Вращение — это чистая CSS-анимация**: она не опирается ни на какие платформенные API, работает везде и ведёт себя идентично на H5 и в WeChat Mini Program.
- **Фигура рендерится по-разному в зависимости от платформы**: на H5 это svg-кольцо с обводкой (двойная анимация `stroke-dasharray`, попиксельно идентичная версии Vue 3); Mini Program не поддерживает svg-теги в шаблонах, поэтому кольцо заменяется на `view` + `border` — три окрашенные стороны образуют дугу примерно в три четверти окружности (визуально изоморфна дуге в 72 % версии Vue 3), а толщина обводки рассчитывается инлайном как 10 % диаметра (минимум 1 px). На обеих платформах вращение управляется CSS-анимацией, поэтому ненадёжные в Mini Program механизмы вроде `transitionend` не задействуются.
- **Цвет идёт через currentColor**: prop `color` записывается в инлайновый стиль `color` корневого узла, и фигура наследует его — так же, как в версии Vue 3.
- **Доступность**: фигура чисто декоративная и убирается из дерева доступности через `aria-hidden="true"`; семантику «выполняется действие» должен нести родительский контейнер (например `role="status"`).
- **Уменьшение анимации**: деградация до статического полукольца при `prefers-reduced-motion` предоставляется исходниками scss `@lh-ui/share`; этот блок media query целиком вырезается при сборке Mini Program (WXSS его не поддерживает), поэтому деградация применяется только на H5.
- **Итог портирования**: Spinner — чисто демонстрационный компонент (без измерений, overlay и зависимости от document); соответствие размеров и имена классов создаются чистыми функциями core `@lh-ui/share` (`getSpinnerClassNames` / `LH_SPINNER_SIZE_PX`), а этот репозиторий пишет только реактивный клей.
