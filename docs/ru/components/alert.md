# Alert (Предупреждение)

Показывает важную смысловую обратную связь на странице (успех / предупреждение / ошибка / информация) с заголовком, описанием, смысловой иконкой и необязательным действием закрытия.

## Базовое использование

```vue
<template>
  <lh-alert title="Уведомление">
    Текущая операция сохранена, редактирование можно продолжить в любое время.
  </lh-alert>
</template>
```

Заголовок можно передать через свойство `title` или одноимённый слот; слот по умолчанию содержит описание.

## Смысловые типы

```vue
<template>
  <lh-alert type="success" title="Успех">
    Данные синхронизированы.
  </lh-alert>
  <lh-alert type="warning" title="Предупреждение">
    Недостаточно средств, пожалуйста, пополните счёт.
  </lh-alert>
  <lh-alert type="danger" title="Ошибка">
    Отправка не удалась, проверьте сеть и повторите попытку.
  </lh-alert>
  <lh-alert type="info" title="Информация">
    Новая версия выйдет на следующей неделе.
  </lh-alert>
</template>
```

## Смысловая иконка

```vue
<template>
  <lh-alert show-icon type="success" title="Сообщение об успехе с иконкой">
    Цвет иконки автоматически соответствует смысловому типу.
  </lh-alert>
</template>
```

## Закрываемый

```vue
<template>
  <lh-alert closable title="Закрываемое предупреждение">
    При нажатии на крестик справа компонент скрывается и генерируется событие close.
  </lh-alert>
</template>
```

## Простой стиль (plain)

```vue
<template>
  <lh-alert plain title="Простой стиль">
    Прозрачный фон со смысловой рамкой, подходит для компактных списков.
  </lh-alert>
</template>
```

## Props

| Свойство | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| type | Смысловой тип | `'info' \| 'success' \| 'warning' \| 'danger'` | `'info'` |
| title | Заголовок (также доступен слот title) | `string` | — |
| closable | Можно ли закрыть | `boolean` | `false` |
| showIcon | Показывать ли смысловую иконку | `boolean` | `false` |
| plain | Использовать ли простой стиль | `boolean` | `false` |
| closeLabel | Доступное имя кнопки закрытия (если не передано, берётся из сообщения `alert.close` локали) | `string` | — |
| customClass | Пользовательский класс | `string` | — |
| sx | Свойства быстрой раскладки | `LhSxProps` | — |

## События

| Событие | Описание | Параметры |
| --- | --- | --- |
| close | Генерируется при нажатии на кнопку закрытия (сразу после компонент скрывается) | — |

## Слоты

| Слот | Описание |
| --- | --- |
| default | Содержимое описания |
| title | Содержимое заголовка (приоритет над свойством title) |

## Различия платформ

- **Роли доступности**: `warning` / `danger` выводятся с `role="alert"` (немедленное объявление), `info` / `success` — с `role="status"` (вежливое объявление), что соответствует семантике APG версии plus; различий между платформами нет.
- **Замена тегов**: `<div>` / `<span>` / `<p>` версии plus заменены на `view` (WXSS запрещает селекторы по тегу, стили применяются через классы `lh-alert__*`).
- **Иконки**: встроенный svg не поддерживается в мини-программе, поэтому используются узлы `lh-icon` (`info` / `check` / `warning` / `error`), а класс `lh-alert__icon` общий со scss из share.
- **Кнопка закрытия**: `<button type="button">` версии plus заменён на `view` с `role="button"`; доступное имя также берётся из `closeLabel` или сообщения `alert.close` (есть на всех девяти языках).
- **Без анимаций появления/исчезновения**: версия plus при закрытии тоже просто удаляет узел через `v-if` (без обёртки `<transition>`), поэтому поведение здесь полностью идентично и проблема ненадёжности события окончания перехода в мини-программе не затрагивается.
- **Итог портирования**: alert — чисто презентационный компонент (без измерений, слоёв, ловушки фокуса и зависимостей от document); он работает на всех платформах с одинаковым поведением на H5 и в мини-программе WeChat.
