# Descriptions (Список описаний)

Отображает список атрибутов объекта с поддержкой количества столбцов, объединения столбцов и режима с рамкой. Записи передаются через `items` (`LhDescriptionsItem` — тип записи из core `@lh-ui/share`), а их содержимое можно переопределить слотами с областью видимости.

## Базовое использование

```vue
<template>
  <lh-descriptions
    title="Карточка экспоната"
    :column="2"
    :items="[
      { label: 'Название', value: 'Сине-белая ваза' },
      { label: 'Эпоха', value: 'Юнлэ, Мин' },
      { label: 'Категория', value: 'Фарфор' },
      { label: 'Категория ценности', value: 'I категория' },
    ]"
  />
</template>
```

## Столбцы и объединение

`column` управляет количеством записей в строке, а `span` записи — сколько столбцов она занимает. `span`, превышающий оставшуюся ширину строки, ограничивается, а неполная последняя строка дополняется ячейками-заполнителями (они чисто декоративные и помечены `aria-hidden`).

```vue
<template>
  <lh-descriptions
    :column="3"
    :items="[
      { label: 'Название', value: 'Тысяча ли рек и гор', span: 2 },
      { label: 'Эпоха', value: 'Северная Сун' },
      { label: 'Художник', value: 'Ван Сымэн' },
      { label: 'Основа', value: 'Тушь и краски на шёлке' },
      { label: 'Хранилище', value: 'Музей Гугун, Пекин' },
    ]"
  />
</template>
```

## Режим с рамкой

`border` включает рамки таблицы (в режиме с рамкой межстрочный интервал обнуляется, а рамки ячеек образуют сетку таблицы).

```vue
<template>
  <lh-descriptions
    :column="2"
    border
    :items="[
      { label: 'Название', value: 'Предисловие из Павильона орхидей' },
      { label: 'Автор', value: 'Ван Си-чжи' },
      { label: 'Эпоха', value: 'Восточная Цзинь' },
      { label: 'Стиль', value: 'Скоропись' },
    ]"
  />
</template>
```

## Пользовательские заголовок и содержимое

Слот `title` переопределяет заголовок; слот с областью видимости `item-<index>` переопределяет содержимое соответствующей записи (`index` — порядковый номер ячейки записи внутри её строки; область видимости предоставляет `{ item }`).

```vue
<template>
  <lh-descriptions :column="2" :items="items">
    <template #title>
      <text>Карточка экспоната (заголовок через слот)</text>
    </template>
    <template #item-1="{ item }">
      <lh-tag type="success">{{ item.value }}</lh-tag>
    </template>
  </lh-descriptions>
</template>

<script setup lang="ts">
const items = [
  { label: 'Статус', value: 'В работе' },
  { label: 'Этап', value: 'Атрибутирован' },
]
</script>
```

## Props

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| title | Заголовок списка | `string` | — |
| column | Количество записей в строке | `number` | `3` |
| border | Показывать ли рамки | `boolean` | `false` |
| items | Список записей; тройки label / value / span | `[LhDescriptionsItem](#lhdescriptionsitem-тип)`[] | `() => []` |
| customClass | Пользовательское имя класса | `string` | — |
| sx | Быстрые свойства layout | `LhSxProps` | — |

## LhDescriptionsItem (тип)

Поступает из core `@lh-ui/share` (`LhDescriptionsItem`); в этом репозитории не переопределяется.

| Свойство | Описание | Тип | Значение по умолчанию |
| --- | --- | --- | --- |
| label | Подпись записи | `string` | — |
| value | Содержимое записи (можно также передать через слот с областью видимости) | `string \| number` | — |
| span | Количество занимаемых столбцов; при превышении ограничивается | `number` | `1` |

## Слоты

| Слот | Описание | Область видимости |
| --- | --- | --- |
| title | Пользовательский заголовок | — |
| item-\<index\> | Переопределяет содержимое записи (index — номер ячейки внутри строки) | `{ item }` |

## Различия платформ

- Чисто демонстрационный компонент, не использующий никаких платформенных API; поведение полностью идентично на H5 и в WeChat Mini Program. Поведение `items` / `column` / `border` / `span` соответствует версии Vue 3.
- Версия Vue 3 использует семантические теги `<dl>/<dt>/<dd>`; этот репозиторий заменяет их на `<view>` (WXSS запрещает селекторы по тегам, стили применяются через классы). Раскладка строк строится на строчном `flex` и процентном `flex-basis`, по тем же формулам расчёта ширины, что и в версии Vue 3.
- Линии таблицы в режиме с рамкой берутся из исходников стилей `@lh-ui/share` и остаются пригодными для Mini Program после очистки в `build-styles` (на выходе только классовые селекторы и свойства, что соответствует белому списку WXSS).
- Агрегация строк (нормализация span, ограничение, перенос строк, дополнение) полностью создаётся чистой функцией `buildDescriptionRows` из `@lh-ui/share`; этот репозиторий пишет только реактивный клей и никогда не копирует реализацию core.
