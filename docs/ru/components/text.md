# Text текст

Компонент типографики «всё в одном» для заголовков, текста, обрезки и копирования; все смысловые модификаторы ложатся на BEM-классы модификаторов.

## Уровень

```vue
<template>
  <lh-text level="h1">Заголовок 1</lh-text>
  <lh-text level="p">Абзац текста</lh-text>
  <lh-text level="caption">Вспомогательная заметка</lh-text>
</template>
```

`level` принимает `h1` ~ `h6` / `p` (по умолчанию) / `caption`. Недопустимое значение снижается до `p`.

## Семантика и модификаторы

```vue
<template>
  <lh-text type="success" strong>Успех и жирность</lh-text>
  <lh-text mark>Подсветка</lh-text>
  <lh-text code>Стиль кода</lh-text>
</template>
```

`type`: `default` (по умолчанию) / `secondary` / `success` / `warning` / `danger`; свойства-модификаторы: `strong` / `italic` / `underline` / `mark` / `code` / `disabled`.

## Обрезка

```vue
<template>
  <lh-text :ellipsis="true">Обрезка в одну строку</lh-text>
  <lh-text :ellipsis="2">Обрезка в две строки</lh-text>
</template>
```

`ellipsis` со значением `true` обрезает до одной строки; число обрезает по количеству строк (максимум 10, многострочная обрезка через инлайновый `-webkit-line-clamp`).

## Копирование

```vue
<template>
  <lh-text copyable copy-text="Фиксированный текст">Скопировать кнопкой</lh-text>
</template>
```

`copyable` добавляет кнопку копирования: клик записывает в буфер обмена, кратко переключается на «Скопировано» и одновременно вызывает событие `copy` (аргумент — фактически записанный текст).

::: tip Копирование на Мини-программе
На H5 при отсутствии `copy-text` текст слота берётся автоматически; **Мини-программа не может прочитать текст слота, поэтому `copy-text` обязателен**, иначе кнопка ничего не запишет (клик всё равно вызывает событие `copy`). Подписи берутся из языкового пакета `text.copy` / `text.copied` и переопределяются через `copy-label`.
:::

## Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| level | Уровень заголовка и форма абзаца | `'h1' \| ... \| 'h6' \| 'p' \| 'caption'` | `'p'` |
| type | Смысловой цвет | `'default' \| 'secondary' \| 'success' \| 'warning' \| 'danger'` | `'default'` |
| strong / italic / underline / mark / code / disabled | Булевы модификаторы | `boolean` | `false` |
| ellipsis | Обрезка: `true` для одной строки, число для количества строк | `boolean \| number` | `false` |
| copyable | Добавляет кнопку копирования | `boolean` | `false` |
| copyLabel | Имя кнопки копирования для доступности | `string` | — |
| copyText | Текст для копирования (обязателен на Мини-программе) | `string` | — |
| customClass | Пользовательский класс | `string` | — |
| sx | Быстрые пропы разметки | `LhSxProps` | — |

## Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| copy | Клик по кнопке копирования | `(text: string)` |

## Платформенные различия

| Возможность | H5 | Мини-программа |
| --- | --- | --- |
| Элемент вывода | view (типографика держится на классах `lh-text--<level>`) | Как на H5 |
| Копирование | Берёт текст слота автоматически без `copy-text` (`navigator.clipboard`) | `copy-text` обязателен; идёт через `uni.setClipboardData` (с системным уведомлением) |
