# Collapse (сворачиваемая панель)

Свёртывает и развёртывает блоки содержимого. Панели могут сосуществовать или работать в режиме аккордеона (одновременно открыта только одна).

## Базовое использование

Без `v-model` компонент неуправляемый: он сам хранит состояние развёрнутости. Клик по строке заголовка переключает состояние, а событие `change` несёт последние развёрнутые панели.

```vue
<template>
  <lh-collapse>
    <lh-collapse-item
      name="a"
      title="Согласованность и разнообразие"
    >
      Сохранять визуальное оформление и взаимодействие, согласованное с остальной страницей.
    </lh-collapse-item>
    <lh-collapse-item
      name="b"
      title="Обратная связь"
    >
      Давать ясный и своевременный отклик после каждого действия.
    </lh-collapse-item>
  </lh-collapse>
</template>
```

## Аккордеон

В режиме `accordion` одновременно открыта максимум одна панель; повторный клик по открытой панели свёртывает все.

```vue
<template>
  <lh-collapse accordion>
    <lh-collapse-item
      name="a"
      title="Только одна открыта"
    >
      Одновременно открыта максимум одна панель.
    </lh-collapse-item>
    <lh-collapse-item
      name="b"
      title="Клик снова — свернуть"
    >
      Можно свернуть всё.
    </lh-collapse-item>
  </lh-collapse>
</template>
```

## Управляемый v-model и отключённые панели

Привяжите развёрнутые панели через `v-model` (одно значение или массив; в режиме аккордеона обычно одно значение); `disabled` отключает отдельную панель.

```vue
<template>
  <lh-collapse v-model="activeNames">
    <lh-collapse-item
      name="a"
      title="Панель A"
    >
      Управляемое содержимое A
    </lh-collapse-item>
    <lh-collapse-item
      name="b"
      title="Панель B (отключена)"
      disabled
    >
      Отключённое содержимое
    </lh-collapse-item>
    <lh-collapse-item
      name="c"
      title="Панель C"
    >
      Управляемое содержимое C
    </lh-collapse-item>
  </lh-collapse>
</template>

<script lang="ts" setup>
import { ref } from 'vue'

const activeNames = ref(['a'])
</script>
```

## Collapse Props

| Prop | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue | Активные панели (управляемый v-model, одно значение или массив) | `LhCollapseKey \| LhCollapseKey[]` | — |
| accordion | Режим аккордеона: одновременно открыта только одна панель | `boolean` | `false` |
| customClass | Пользовательский класс (применяется к корневому узлу) | `string` | — |
| sx | Быстрые props раскладки | `LhSxProps` | — |

## CollapseItem Props

| Prop | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| name | Уникальный идентификатор панели (обязательный) | `string \| number` | — |
| title | Заголовок (также есть слот `title`) | `string` | — |
| disabled | Отключена ли панель | `boolean` | `false` |
| customClass | Пользовательский класс (применяется к корневому узлу элемента) | `string` | — |
| sx | Быстрые props раскладки | `LhSxProps` | — |

## События

| Событие | Описание | Аргументы |
| --- | --- | --- |
| update:modelValue | Развёрнутые панели изменились (управляемый v-model; компонент не хранит внутреннее состояние) | `(value: LhCollapseKey \| LhCollapseKey[])` |
| change | Развёрнутые панели изменились (неуправляемый; в аккордеоне одно значение, `undefined` при полностью свёрнутом состоянии) | `(value: LhCollapseKey \| LhCollapseKey[])` |

## Слоты

| Слот | Описание |
| --- | --- |
| Collapse default | Узлы элементов панелей (`lh-collapse-item`) |
| CollapseItem default | Содержимое панели |
| CollapseItem title | Заголовок панели (переопределяет prop `title`) |

## Различия платформ

- **Анимация свёртывания / развёртывания — чистый CSS**: `grid-template-rows` переключается между `0fr / 1fr`, а стрелка поворачивается через `transform`. Ничто не слушает `transitionend` (он ненадёжен в WeChat Mini Program, поэтому библиотека вообще от него не зависит). Переключение класса применяется мгновенно: даже если какой-либо движок рендеринга MP не поддерживает grid-переходы, итоговое развёрнутое состояние всё равно корректно — страдает лишь анимация.
- **Содержимое рендерится всегда** (без условного `v-if`): видимость `lh-collapse__wrap` переключается классом `--active`. Если нужно рендерить содержимое только при развёртывании, управляйте этим сами через `v-if` со стороны содержимого.
- `<h3>` / `<button>` заменены на `<view>` / `<text>` (WXSS запрещает селекторы по тегам); отключённое состояние больше не полагается на нативный `<button disabled>`, а выражается через перехват клика + класс `--disabled` + `aria-disabled`.
- Семантика доступности выводится на обеих платформах: заголовок несёт `role="button"` + `aria-expanded` / `aria-controls`, а область содержимого — `role="region"` + `aria-labelledby`. Поддержка скринридеров в MP зависит от платформы. На H5 сфокусированный заголовок естественно отзывается на Enter / Space.
- Связующие `id` заголовка и содержимого генерируются локально уникальными через `generateId` (а не `useId` из Vue 3.5 — ради совместимости с ядрами Vue в uni-app), поэтому несколько групп сворачивания на одной странице не конфликтуют.
- **Решение по переносу (выровнен с версией Vue3, никаких выдуманных API)**: перенос строго следует источнику истины plus и предоставляет только `v-model` (одно значение / массив), `accordion`, `name` / `title` / `disabled` панели и слот `title`. То, чего нет в источнике (вложенные сворачивания, слот иконки, ленивый рендер и т. п.), не добавляется по собственной инициативе; перенос последует за источником, когда они там появятся.
- В слое клея этого репозитория есть одна правка чтения управляемого состояния (записана в changeset): в управляемом режиме развёрнутое состояние — это computed, подписанный на `props.modelValue`, поэтому панели немедленно следуют за асинхронно обновлённым v-model. Чистые функции core и контракт props полностью идентичны plus.
