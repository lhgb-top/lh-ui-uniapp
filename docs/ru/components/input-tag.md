# InputTag ввод тегов

Группа тегов, отправляемых прямо при вводе, с клавишами отправки, лимитом, дедупликацией и удалением по клику.

## Базовое использование

```vue
<script setup>
import { ref } from 'vue'
const tags = ref(['тушь', 'пустота'])
</script>

<template>
  <lh-input-tag v-model="tags" placeholder="Введите и нажмите Enter" />
</template>
```

## Клавиши отправки

`trigger` принимает `enter` (по умолчанию) / `space` / `comma`. При отправке через `space` / `comma` пробел не попадает в поле.

```vue
<template>
  <lh-input-tag v-model="tags" trigger="comma" placeholder="Введите запятую для отправки" />
</template>
```

## Лимит и дедупликация

```vue
<template>
  <lh-input-tag v-model="tags" :max="3" allow-duplicate />
</template>
```

Положительный `max` задаёт лимит (при превышении отправка отклоняется, а поле очищается); по умолчанию дубликаты отклоняются (повторный тег не отправляется).

## Только чтение и отключение

```vue
<template>
  <lh-input-tag v-model="tags" readonly />
  <lh-input-tag v-model="tags" disabled />
</template>
```

## Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue | Список тегов (v-model) | `string[]` | `[]` |
| trigger | Клавиша отправки (на Мини-программе всегда клавиша Готово) | `'enter' \| 'space' \| 'comma'` | `'enter'` |
| placeholder | Подсказка (показывается только при отсутствии тегов) | `string` | `''` |
| placeholderStyle | Стиль подсказки (заменяет `::placeholder`) | `string` | — |
| max | Лимит тегов (неположительное значение — без лимита) | `number` | `0` |
| allowDuplicate | Разрешить дубликаты тегов | `boolean` | `false` |
| readonly | Только чтение | `boolean` | `false` |
| disabled | Отключено | `boolean` | `false` |
| ariaLabel | Имя для доступности | `string` | — |
| customClass | Пользовательский класс | `string` | — |
| sx | Быстрые пропы разметки | `LhSxProps` | — |

## Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Изменился список тегов | `(value: string[])` |
| change | Изменился список тегов (то же, что modelValue) | `(value: string[])` |
| add | Отправлен один тег | `(tag: string)` |
| remove | Удалён один тег | `(tag: string)` |

## Методы (defineExpose)

| Метод | Описание |
| --- | --- |
| focus | Устанавливает фокус в поле |
| commit | Отправляет текущий ввод |

## Платформенные различия

| Возможность | H5 | Мини-программа |
| --- | --- | --- |
| Клавиша отправки | Поддерживаются все значения `trigger` (события клавиатуры Enter / Space / Comma) | Всегда **клавиша Готово** (`@confirm`); значения `space` / `comma` доступны только на H5 |
| Удаление через Backspace | Backspace удаляет последний тег, когда поле пустое | Событий клавиатуры нет; удаление через **кнопку ×** на каждом теге (доступно на обеих платформах) |
| Отправка при потере фокуса | Да | Да |
| Граница фокуса | Стиль фокуса через `:has()` применяется | Границы фокуса нет (WXSS не поддерживает `:has()`); ввод работает штатно |
