# Mentions

Поле упоминания участников, срабатывающее при вводе `@`; поддерживает фильтрацию, многострочность и callback выбора.

## Базовое использование

```vue
<script setup>
import { ref } from 'vue'
const value = ref('')
const members = [
  { label: 'Тушь', value: 'ink' },
  { label: 'Пустое пространство', value: 'blank' },
]
</script>

<template>
  <lh-mentions v-model="value" :options="members" />
</template>
```

После ввода `@` открывается панель подсказок, а дальнейший ввод фильтрует список по label. При выборе в поле записывается `label` (читаемое человеком `@Тушь `), а машиночитаемый идентификатор `value` передаётся в бизнес-слой через событие `select`.

## Многострочность

```vue
<template>
  <lh-mentions v-model="value" :options="members" multiline />
</template>
```

`multiline` заменяет однострочный input на textarea.

## Символ триггера

```vue
<template>
  <lh-mentions v-model="value" :options="members" prefix="#" />
</template>
```

По умолчанию `prefix` равен `'@'`; псевдопрефикс, непосредственно прилегающий к символу слова ASCII (например `user@` в адресе электронной почты), не запускает упоминание.

## Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue | Содержимое текста (v-model) | `string` | `''` |
| options | Участники-кандидаты | `LhMentionOption[]` | `[]` |
| prefix | Символ триггера | `string` | `'@'` |
| placeholder | Текст-заполнитель (по умолчанию из сообщения локали mentions.placeholder) | `string` | — |
| placeholderStyle | Стиль текста-заполнителя (заменяет `::placeholder`) | `string` | — |
| disabled | Отключить компонент | `boolean` | `false` |
| multiline | Многострочный textarea | `boolean` | `false` |
| ariaLabel | Доступное имя | `string` | — |
| customClass | Пользовательский класс | `string` | — |
| sx | Быстрые свойства макета | `LhSxProps` | — |

## Слоты

| Слот | Описание |
| --- | --- |
| empty | Пустое состояние при отсутствии совпадений (текст по умолчанию берётся из сообщения локали mentions.noMatch) |

## Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Записывает значение после ввода или выбора | `(value: string)` |
| change | Текст изменился | `(value: string)` |
| select | Выбрано упоминание | `(option: LhMentionOption)` |

## Методы (defineExpose)

| Метод | Описание |
| --- | --- |
| updateContext | Обновить контекст курсора вручную |
| close | Закрыть панель подсказок |

## Платформенные различия

| Возможность | H5 | Мини-программа |
| --- | --- | --- |
| Позиционирование выпадающего списка | root-portal + двухкадровое измерение (как у select) | Alipay использует root-portal или фиксированное позиционирование внутри страницы в зависимости от версии базовой библиотеки; Douyin — фиксированное внутри страницы |
| Контекст курсора | Нативный `selectionStart` (упоминание можно запустить в середине текста) | **Позиция курсора недоступна и аппроксимируется концом текста** — запуск упоминания в середине уже введённого текста не работает и деградирует до вставки в конце |
| Навигация с клавиатуры / Esc | Стрелки перемещают подсветку, Enter выбирает, Esc закрывает | События клавиатуры отсутствуют; выбор только нажатием |
| Позиция курсора после выбора | Устанавливается точно после упоминания | После контролируемой записи курсор остаётся в конце |
