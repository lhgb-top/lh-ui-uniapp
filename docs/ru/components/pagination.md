# Pagination

Постраничная навигация: предыдущая страница / номера страниц / многоточие / следующая страница /
общее количество / выбор размера страницы / переход к странице. Алгоритм сжатия окна страниц
(первая и последняя страницы всегда видны, соседние страницы вокруг текущей, многоточие только при
реальном разрыве) реализован чистой функцией в ядре `@lh-ui/share`.

## Базовое использование

`total` — общее количество элементов данных (обязательный); размер страницы по умолчанию — 10.

```vue
<template>
  <lh-pagination :total="120" />
</template>
```

## Общее количество и выбор размера страницы

`show-total` показывает общее количество; `show-size-changer` показывает переключатель количества
элементов на странице (в uni его несёт встроенный picker).

```vue
<template>
  <lh-pagination :total="480" show-total show-size-changer />
</template>
```

## Переход к странице

`show-jumper` показывает поле перехода; после ввода номера страницы подтвердите клавишей Enter
(confirm) или при потере фокуса, значения вне диапазона автоматически ограничиваются.

```vue
<template>
  <lh-pagination :total="480" show-total show-jumper />
</template>
```

## Простой режим

`simple` сворачивает зону номеров страниц и показывает только «текущая страница / всего страниц».

```vue
<template>
  <lh-pagination :total="480" simple show-jumper />
</template>
```

## Управляемое использование

Текущая страница управляется через `v-model:current`.

```vue
<template>
  <lh-pagination v-model:current="page" :total="95" />
  <text>Текущая страница: {{ page }}</text>
</template>

<script setup>
import { ref } from 'vue'
const page = ref(2)
</script>
```

## Размер страницы и блокировка

`v-model:page-size` управляет размером страницы, `page-sizes` задаёт варианты; если после изменения
размера текущая страница выходит за пределы, она автоматически ограничивается; `disabled`
блокирует всю пагинацию.

```vue
<template>
  <lh-pagination
    v-model:page-size="pageSize"
    :total="480"
    show-size-changer
    :page-sizes="[10, 20, 50, 100]"
  />
  <text>Элементов на странице: {{ pageSize }}</text>
  <lh-pagination :total="480" disabled />
</template>

<script setup>
import { ref } from 'vue'
const pageSize = ref(20)
</script>
```

## Props

| Свойство | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| total | Общее количество элементов (обязательное) | `number` | — |
| pageSize | Элементов на странице (управляется событием `update:pageSize`) | `number` | `10` |
| current | Текущая страница (`v-model:current`) | `number` | — |
| pageSizes | Варианты количества элементов на странице | `number[]` | `[10, 20, 30, 40]` |
| showTotal | Показывать общее количество | `boolean` | `false` |
| showSizeChanger | Показывать переключатель размера страницы | `boolean` | `false` |
| showJumper | Показывать поле перехода к странице | `boolean` | `false` |
| simple | Компактный режим | `boolean` | `false` |
| disabled | Заблокировано ли | `boolean` | `false` |
| sx | Быстрые свойства раскладки | `LhSxProps` | — |

## Events

| Событие | Описание | Параметры callback |
| --- | --- | --- |
| update:current | Срабатывает при смене текущей страницы, вместе с `v-model:current` | `(page: number)` |
| update:pageSize | Срабатывает при смене размера страницы, вместе с `v-model:page-size` | `(size: number)` |
| change | Срабатывает при смене текущей страницы (номера страниц, вперёд / назад и переход) | `(page: number)` |
| size-change | Срабатывает при смене размера страницы | `(size: number)` |

## Доступность

- Корневой узел `role="navigation"` + `aria-label="pagination"`
- Кнопка текущей страницы автоматически получает `aria-current="page"`; у каждой кнопки страницы и
  кнопок вперёд / назад есть собственный `aria-label` (из ключей языкового пакета `pagination.page` /
  `prev` / `next`); чистые символы «‹» «›» скрыты через `aria-hidden`
- Кнопки страниц и навигации имеют `role="button"` и выдают `aria-disabled` при блокировке
- Многоточие — чисто декоративный элемент с `aria-hidden`, не мешающий чтению

## Отличия платформ

- **Тач-взаимодействие нарисованным view, доступно на всех платформах**: `<nav>` / `<button>` /
  `<ul>` / `<span>` версии Vue 3 заменены на `<view>` / `<text>` (WXSS запрещает селекторы
  тегов, стили вешаются классами); номера страниц и навигация срабатывают по `@click` и ведут себя
  одинаково на H5 и в мини-программе WeChat, без зависимости от платформенных API.
- **Логика многоточия при переполнении страниц живёт в core**: алгоритм сжатия окна (первая /
  последняя страницы всегда видны, по одной соседней странице с каждой стороны текущей, прижатие к
  краям при нехватке, многоточие только при реальном разрыве) — это чистая функция
  `getPaginationRange` ядра `@lh-ui/share`; ограничение `clampPage` и подсчёт `getPageCount`
  также идут из core — репозиторий добавляет только реактивную прослойку.
- **Переключатель размера несёт встроенный picker**: в uni нет `<select>`, поэтому
  `show-size-changer` несёт встроенный `<picker mode="selector">` uni с вариантами из
  `page-sizes`; значение события change приходит в `event.detail.value` (индекс варианта).
  На H5 открывается панель выбора uni, в мини-программе — нативное колёсико.
- **Поле перехода подтверждается в другой момент**: у input в uni нет нативного события change,
  поэтому подтверждение происходит по Enter (confirm — срабатывает и клавиша Enter на H5, и
  кнопка «Готово» клавиатуры мини-программы) или при потере фокуса (blur), а значение события
  ввода читается из `event.detail.value` (тот же прецедент, что и у lh-input-number); нативные
  атрибуты `min` / `max` не пробрасываются — номер страницы всегда ограничивает `clampPage` из
  core. Версия Vue 3 при очистке поля и потере фокуса возвращается на страницу 1; эта библиотека
  ужесточает поведение до «не переходить» (пустые строки и некорректные числа событий не шлют).
- **Заблокированный вид через класс-фолбэк**: заблокированные стили в источнике стилей share
  живут на псевдоклассе `&:disabled` (соответствует только элементам button), а у view такого
  псевдокласса нет, поэтому компонент добавляет инлайн-правило `lh-pagination__btn--disabled`
  с тем же токеном (`--lh-disabled-text-color`) — по прецеденту инлайн-фолбэков
  lh-segmented / lh-input-number (в очищенный артефакт не входит).
- **Атрибуты доступности привязываются по одному**: контракт `aria-current` / `aria-label`
  кнопок страниц определяет `getPaginationItemAria` из share; поскольку компилятор шаблонов
  мини-программы не поддерживает `v-bind` объектом, клеевой слой разворачивает набор атрибутов
  в явные привязки по элементам.
- **Вывод по портированию**: Pagination — чисто переключательный компонент без измерений, без
  оверлеев и без зависимости от document; диапазон страниц, ограничение и атрибуты доступности
  целиком производят чистые функции ядра `@lh-ui/share`, репозиторий добавляет только реактивную
  прослойку. API полностью совпадает с версией Vue 3 (`total` / `pageSize` / `current` /
  `pageSizes` / `showTotal` / `showSizeChanger` / `showJumper` / `simple` / `disabled` / `sx`).
