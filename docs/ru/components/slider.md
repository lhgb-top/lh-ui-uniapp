# Slider

Ползунок, позволяющий выбирать значение перетаскиванием бегунка вдоль дорожки. Поддерживаются режимы с одним бегунком и с диапазоном (два бегунка), привязка к шагу `step` и метки делений `marks`. Дорожка, бегунки и полоса заполнения полностью отрисованы средствами `view`; ограничение значений, привязка к шагу, сортировка делений и контракт доступности берутся напрямую из чистых функций `@lh-ui/share` (без копирования).

## Базовое использование

```vue
<template>
  <lh-slider v-model="value" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref(30)
</script>
```

Если `modelValue` не передан, компонент инициализируется значением `min`; передача делает компонент управляемым (как и все остальные компоненты форм). Во время перетаскивания обновляется только внутреннее состояние — `update:modelValue` / `change` генерируются **один раз, при отпускании** (как в версии Vue3).

## Выбор диапазона

`range` включает режим с двумя бегунками; `modelValue` — кортеж `[начало, конец]`:

```vue
<template>
  <lh-slider v-model="span" range />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const span = ref<[number, number]>([20, 60])
</script>
```

При перетаскивании одного конца за другой концы меняются местами (перетаскивается всегда тот бегунок, что под пальцем), значение всегда остаётся `[раньше, позже]`.

## Шаг и деления

`step` привязывает бегунок к сетке шага; `marks` отрисовывает метки делений по соответствию `значение → текст` (сортировка по значению):

```vue
<template>
  <lh-slider v-model="value" :min="0" :max="100" :step="10" :marks="marks" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const value = ref(30)
const marks: Record<number, string> = {
  0: '0',
  50: 'Середина',
  100: 'Максимум',
}
</script>
```

## Отключение

`disabled` блокирует перетаскивание и управление с клавиатуры и убирает бегунок из порядка табуляции:

```vue
<template>
  <lh-slider v-model="value" disabled />
</template>
```

## Отображение значения

`show-input` показывает текущее значение справа от дорожки (в режиме диапазона — строка `[начало, конец]`):

```vue
<template>
  <lh-slider v-model="value" show-input />
</template>
```

## Slider API

### Props

| Свойство | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| modelValue | Текущее значение (управляемый v-model; кортеж в режиме диапазона) | `number \| [number, number]` | — |
| min | Минимальное значение | `number` | `0` |
| max | Максимальное значение | `number` | `100` |
| step | Шаг (минимальная единица привязки бегунка) | `number` | `1` |
| disabled | Отключить весь компонент | `boolean` | `false` |
| range | Режим диапазона (два бегунка) | `boolean` | `false` |
| showInput | Показывать текущее значение рядом с дорожкой | `boolean` | `false` |
| size | Размер | `'small' \| 'medium' \| 'large'` | `'medium'` |
| marks | Метки делений (ключи — значения, сортировка по возрастанию) | `Record<number, string>` | — |
| customClass | Пользовательский класс, передаваемый корневому узлу | `string` | — |
| sx | Быстрые свойства разметки (применяются к корневому узлу) | `LhSxProps` | — |

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| update:modelValue | Значение изменилось (v-model; генерируется при отпускании или шаге с клавиатуры) | `(value: number \| [number, number])` |
| change | Значение изменилось (тот же payload, что у update:modelValue) | `(value: number \| [number, number])` |

### Доступность

- Бегунок имеет `role="slider"` с `aria-valuemin` / `aria-valuemax` / `aria-valuenow` / `aria-valuetext` (контракт определяется `getSliderThumbAria` из share)
- В режиме диапазона два бегунка несут разные `aria-label` («бегунок начала / бегунок конца», ключи локали `slider.thumbStart` / `slider.thumbEnd`, иначе `slider.thumb`)
- Управление с клавиатуры (стрелки двигают на `step`, PageUp / PageDown — крупные шаги, Home / End — переход к краям) работает только в H5 — см. различия платформ ниже

::: tip Различия платформ (отличия от версии Vue3)
- **Носитель перетаскивания**: plus вешает `mousedown` / `touchstart` на бегунок, а затем переносит слушатели move / up на `document`; у мини-программы нет document, поэтому `touchstart` / `touchmove` / `touchend` остаются привязанными к самому бегунку (события touch в мини-программе продолжают приходить на цель touchstart — глобальные слушатели не нужны). В H5 сохраняются слушатели мыши на уровне document (после нажатия перетаскивание продолжается и за пределами компонента), они защищены условной компиляцией — в MP-бандле нет мёртвого кода.
- **Расчёт положения асинхронен**: plus измеряет дорожку синхронным `getBoundingClientRect`; у мини-программы есть только асинхронный `createSelectorQuery`, поэтому компонент использует `getSingleLhRect` из адаптера. Результат измерения кэшируется на сессию перетаскивания (предваряется на touchstart), обычное перетаскивание почти не страдает; но семантически обновление значения отстаёт от касания на один кадр. **Не предполагайте внутри события move, что значение уже обновилось синхронно** — генерация происходит только при отпускании.
- **Нулевая ширина дорожки пропускается**: если вёрстка ещё не готова (или в тестовом окружении), ширина прямоугольника дорожки равна нулю, что привело бы к делению на ноль; такое обновление пропускается, чтобы не загрязнять значение NaN.
- **Управление с клавиатуры только в H5**: шаги стрелками / Home / End / PageUp / PageDown не имеют клавиатурных событий в MP, защищённый код вообще не вызывается — мёртвого кода в MP-бандле нет.
- **Атрибуты aria привязываются по одному**: пакет `LhAriaAttrs` из share нельзя развернуть через `v-bind` (компилятор шаблонов MP этого не поддерживает); слой-клей разворачивает ключи `aria-*` в явные привязки, контракт по-прежнему определяют чистые функции share.
- **Нет вертикального режима и всплывающей подсказки**: в исходниках plus нет ни свойства `vertical` (вертикальная дорожка), ни всплывающей подсказки; этот порт строго следует им и ничего не добавляет. Для вертикальной дорожки можно повернуть обёрточный контейнер (координаты касания обработав самостоятельно), а для показа значения использовать `show-input`, чтобы оно оставалось видимым.
:::
