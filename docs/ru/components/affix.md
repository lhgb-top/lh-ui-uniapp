# Affix Фиксация

Фиксирует содержимое в верхней или нижней части области просмотра. Решение о
зафиксированном состоянии (`isAffixFixed`) и зафиксированный стиль
(`getAffixFixedStyle`) берутся из чистых функций core `@lh-ui/share`; слой
компонента отвечает только за подписку на прокрутку, измерение
элемента-заполнителя и реактивную привязку.

## Платформенные различия (важно)

Семантика прокрутки на H5 и в мини-программе WeChat отличается, поэтому компонент
использует двухплатформенный подход:

- **H5**: компонент самостоятельно слушает событие `scroll` у `window` (или у
  контейнера, на который указывает селектор `target`), а состояние фиксации
  определяет по `getBoundingClientRect` узла-заполнителя.
- **Мини-программа WeChat**: событие `scroll` можно привязать только к тегу
  `scroll-view`, поэтому компонент не может подписаться сам. Поместите компонент
  внутрь `scroll-view` и передайте `detail.scrollTop` события прокрутки через
  prop `scrollTop`:

```vue
<template>
  <scroll-view
    class="my-scroll"
    :scroll-y="true"
    :scroll-top="scrollTop"
    @scroll="onScroll"
  >
    <lh-affix :scroll-top="scrollTop" :offset-top="20">
      <view class="my-bar">Закрепляемая панель</view>
    </lh-affix>
    <!-- длинное содержимое -->
  </scroll-view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const scrollTop = ref(0)
function onScroll(event: { detail?: { scrollTop?: number } }) {
  scrollTop.value = event.detail?.scrollTop ?? 0
}
</script>
```

На H5, если `scrollTop` не передан, компонент автоматически слушает `window`; если
передан селектор `target` — слушает соответствующий контейнер.

## Базовое использование

```vue
<template>
  <lh-affix :offset-top="20">
    <lh-button type="primary">Закрепляемая кнопка</lh-button>
  </lh-affix>
</template>
```

Когда содержимое при прокрутке проходит `offset-top`, оно фиксируется в верхней
части области просмотра; после фиксации элемент-заполнитель удерживает позицию
документа на исходной высоте, поэтому последующее содержимое не сдвигается
рывком.

## Режим фиксации снизу

```vue
<template>
  <lh-affix :offset-bottom="24">
    <view class="my-bar">Нижняя закрепляемая панель</view>
  </lh-affix>
</template>
```

`offset-bottom` имеет приоритет над `offset-top`: нижний край заполнителя
фиксируется внизу, как только проходит «высота области просмотра - offset-bottom».

## API

### Props

| Проп | Описание | Тип | По умолчанию |
| --- | --- | --- | --- |
| offset-top | Сколько пикселей от верха области просмотра запускают фиксацию сверху | `number` | `0` |
| offset-bottom | Сколько пикселей от низа области просмотра запускают фиксацию снизу (приоритет над offset-top) | `number` | `0` |
| target | Селектор контейнера прокрутки на H5 (по умолчанию область просмотра; не действует на MP) | `string` | `-` |
| scrollTop | Внедрение позиции прокрутки (MP: `detail.scrollTop` у scroll-view) | `number` | `-` |
| sx | Быстрые пропы разметки (отступы / размеры / flex) | `LhSxProps` | `-` |

### Events

| Событие | Описание | Параметры |
| --- | --- | --- |
| change | Срабатывает при изменении зафиксированного состояния | `(fixed: boolean)` |

### Slots

| Слот | Описание |
| --- | --- |
| default | Содержимое для фиксации |
